实务-股权转让与出资责任

实务专题 3899字 10 分钟阅读

一、问题引入：股权转让中出资责任如何分配

股权转让是公司法实务中最为常见的交易类型之一。在股权转让过程中，一个核心且复杂的问题是：转让人（原股东）的出资义务如何在转让人与受让人之间分配？

这一问题在新《公司法》实施后变得尤为重要，原因在于：

  • 新《公司法》全面实行五年限期认缴制，大量存量公司面临调整出资期限的压力；
  • 未届期股权转让的情形将大幅增加；
  • 新《公司法》第88条明确了转让人的补充出资责任，这对股权转让实务产生了深远影响。

二、法律框架

（一）有限公司股权转让规则

◆ 核心规则：《公司法》第84条规定了有限公司股权转让的基本规则。

股东之间转让：股东之间可以相互转让其全部或者部分股权，无需其他股东同意。

向股东以外的人转让：

  • 应当将股权转让的有关事项书面通知其他股东；
  • 其他股东自接到书面通知之日起三十日内未答复的，视为同意转让；
  • 其他股东半数以上不同意转让的，不同意的股东应当购买该转让的股权；不购买的，视为同意转让；
  • 经股东同意转让的股权，在同等条件下，其他股东有优先购买权。

章程自治：公司章程对股权转让另有规定的，从其规定。但章程不得禁止股权转让，只能对转让条件作出合理限制。

（二）股份公司股份转让规则

《公司法》第157-164条规定了股份有限公司的股份转让规则：

转让场所 限制类型 具体规则
依法设立的证券交易场所 发起人 公司成立之日起一年内不得转让
或按照国务院规定的其他方式 公司公开发行前已发行的股份 自公司股票在证券交易所上市交易之日起一年内不得转让
董监高 任职期间每年转让不超过所持股份的25%，离职后半年内不得转让

三、◆ 未届期股权转让

（一）新《公司法》第88条：转让人的补充出资责任

◆ 核心规则：《公司法》第88条第1款规定：

股东转让已认缴出资但未届出资期限的股权的，由受让人承担缴纳该出资的义务；受让人未按期足额缴纳出资的，转让人对受让人未按期缴纳的出资承担补充责任。

这一条文确立了以下规则：

1. 受让人的出资义务

  • 受让人取得股权后，承继该股权上附着的出资义务；
  • 受让人应当按照原出资期限缴纳出资；
  • 这是受让人作为股东的基本义务。

2. 转让人的补充出资责任

  • 转让人不因股权转让而完全免除出资责任；
  • 当受让人未按期足额缴纳出资时，转让人承担补充责任；
  • 补充责任意味着：先由受让人承担责任，受让人不能清偿的部分由转让人承担。

3. 责任分配的逻辑

责任主体 责任类型 责任范围 责任顺序
受让人 直接责任 全部未缴出资 第一顺位
转让人 补充责任 受让人不能清偿部分 第二顺位

（二）实务影响

▲ 新《公司法》第88条对股权转让实务的重大影响：

  • "甩锅式转让"不再可行——转让人不能通过转让未届期股权逃避出资义务；
  • 受让人在受让股权前必须充分评估目标公司的出资义务；
  • 转让人在转让后仍面临被追索的风险，需关注受让人的履约能力。

四、◆ 出资瑕疵股权转让

（一）瑕疵出资的类型

▲ 实务重难点：瑕疵出资是指股东未按照法律规定或公司章程约定全面履行出资义务的情形，主要包括：

1. 未足额出资

  • 货币出资未全额缴纳；
  • 非货币出资仅部分交付或未办理权属转移。

2. 非货币出资评估过高

  • 实际价值显著低于认缴出资额；
  • 评估机构出具不实评估报告。

3. 抽逃出资

  • 出资后通过虚构交易、关联交易等方式抽回出资；
  • 利用关联关系转移公司资产。

（二）转让人的责任不因转让而免除

◆ 核心规则：《公司法》第88条第2款规定：

未按照公司章程规定的出资日期缴纳出资或者作为出资的非货币财产的实际价额显著低于所认缴的出资额的股东转让股权的，转让人与受让人在出资不足的范围内承担连带责任；受让人不知道且不应当知道存在上述情形的，由转让人承担责任。

责任分配规则：

  • 转让人：对瑕疵出资承担终局责任，不因转让而免除；
  • 受让人：知道或应当知道瑕疵出资的，承担连带责任；
  • 受让人：不知道且不应当知道的，不承担责任。

（三）受让人的连带责任

"知道或应当知道"的认定标准：

情形 是否认定知情 说明
受让人参与公司经营 是 作为董事、高管等参与管理
转让价格明显偏低 是 价格异常反映股权瑕疵
受让人进行尽调发现 是 尽调报告已揭示瑕疵
工商登记显示未实缴 视情况 工商信息可公开查询
受让人为关联方 视情况 关联关系增加知情推定

五、▲ 优先购买权的实务操作

（一）"同等条件"的认定

▲ 实务重难点：优先购买权的行使以"同等条件"为前提，但"同等条件"的认定标准在实务中存在争议。

主要考量因素：

  • 价格因素：转让价格是否相同（核心因素）；
  • 付款方式：一次性付款还是分期付款；
  • 付款期限：付款时间是否一致；
  • 其他条件：如对公司的经营承诺、竞业限制等。

裁判规则：同等条件的认定应当综合考虑上述因素，不能仅以价格相同即认定为同等条件，但价格是最重要的考量因素。

（二）通知义务与行使期限

通知义务：

  • 股东向股东以外的人转让股权的，应当将股权转让的有关事项书面通知其他股东；
  • 通知应当包含转让价格、付款方式、付款期限等主要交易条件；
  • 通知的方式应当确保其他股东能够收到。

行使期限：

  • 其他股东自接到书面通知之日起30日内行使优先购买权；
  • 逾期未答复的，视为放弃优先购买权；
  • 公司章程对行使期限另有规定的，从其规定。

（三）损害优先购买权的救济

救济途径：

  1. 主张转让合同无效：未经其他股东同意的股权转让，其他股东可以主张合同无效；
  2. 请求损害赔偿：因优先购买权被侵害导致的损失，可以请求赔偿；
  3. 行使优先购买权：在知道或应当知道转让条件后的合理期限内行使。

▲ 注意：司法实践中，损害优先购买权的股权转让合同并非当然无效，而是可撤销。其他股东可以选择是否行使撤销权。

六、▲ 股权转让协议审查清单

在审查股权转让协议时，应逐项核查以下内容：

审查清单

  • [ ] 1. 股东资格确认

    • 转让人是否为公司登记股东；
    • 是否存在代持关系；
    • 股权是否被冻结或质押。

  • [ ] 2. 出资情况核实

    • 出资是否已实缴；
    • 未实缴的出资期限是否届满；
    • 是否存在瑕疵出资情形；
    • 非货币出资是否经过评估。

  • [ ] 3. 是否存在转让限制

    • 公司章程是否对股权转让设有特别限制；
    • 是否存在竞业限制或锁定期约定；
    • 是否需要取得第三方同意（如融资协议中的限制条款）。

  • [ ] 4. 优先购买权的处理

    • 是否已通知其他股东；
    • 其他股东是否放弃优先购买权；
    • 是否存在损害优先购买权的风险。

  • [ ] 5. 工商变更登记

    • 是否约定了办理工商变更登记的期限；
    • 是否约定了不配合办理变更登记的违约责任；
    • 是否需要同步修改公司章程和股东名册。

  • [ ] 6. 出资责任的约定

    • 未届期出资义务由谁承担；
    • 瑕疵出资的责任如何分配；
    • 是否约定了出资担保条款。

七、对赌协议中股权转让的特殊问题

对赌协议中的股权回购条款涉及股权转让的特殊规则，详见对赌协议实务。

核心问题：

  • 对赌回购是否构成股权转让？——一般认为构成；
  • 公司作为回购主体时，是否需要履行减资程序？——需要；
  • 对赌回购与资本维持原则的关系？——详见对赌协议专题。

八、典型案例

案例：未届期股权转让的出资责任

基本案情：甲、乙、丙三人共同设立A公司，注册资本1000万元，甲认缴400万元，出资期限为2030年。2025年，甲将其全部股权以100万元的价格转让给丁。后A公司无力清偿债务，债权人要求甲承担出资责任。

争议焦点：甲转让未届期股权后，是否仍需承担出资责任？

分析结论：

  1. 甲转让的是未届出资期限的股权，适用《公司法》第88条第1款；
  2. 丁作为受让人，应当承担缴纳出资的义务；
  3. 丁未按期缴纳出资的，甲承担补充责任；
  4. 甲以100万元低价转让400万元股权，存在逃避出资义务的嫌疑；
  5. 结论：丁应当缴纳400万元出资，甲对丁不能清偿的部分承担补充责任。

实务要点：未届期股权转让后，受让人承担直接出资义务，转让人承担补充责任。转让人不能通过转让股权完全免除出资义务。

参考：《公司法》第88条（未届期股权转让的出资责任）。

九、总结

股权转让中的出资责任分配是新《公司法》的重要制度创新。第88条的补充出资责任制度有效防止了"金蝉脱壳"式的股权转让，保护了公司债权人的利益。

核心要点：

  1. 未届期股权转让后，受让人承担出资义务，转让人承担补充责任；
  2. 瑕疵出资股权转让后，转让人不免责，知情受让人承担连带责任；
  3. 优先购买权的行使以"同等条件"为前提，核心是价格因素；
  4. 股权转让协议审查应重点关注出资情况和转让限制；
  5. 对赌回购涉及股权转让的特殊规则，需特别关注。
