实务-公司决议效力判断

实务专题 4489字 12 分钟阅读

一、问题引入：公司决议效力争议的类型化分析

公司决议是公司意思形成的核心机制。股东会决议和董事会决议作为公司最高决策的形式，其效力直接关系到公司行为的合法性基础。在实务中，公司决议效力争议是公司诉讼中最常见的类型之一。

典型争议场景：

  • 未实际召开会议却形成了"决议"；
  • 会议通知程序存在瑕疵；
  • 表决权比例未达到法定或章程要求；
  • 决议内容违反法律或公司章程；
  • 利害关系股东参与表决。

这些问题的核心是：在公司决议存在程序或内容瑕疵时，如何判断其效力？ 新《公司法》建立了"不成立—可撤销—无效"三层次的效力判断体系，为司法实践提供了清晰的裁判框架。

二、法律框架

新《公司法》第25-28条建立了公司决议效力的三层次体系：

效力状态 法律条文 瑕疵类型 法律后果
不成立 第25条 严重程序瑕疵 自始不存在
无效 第25条 内容违法 自始无效
可撤销 第26条 程序/内容违反章程 可撤销

三、◆ 决议不成立（第25条）

（一）法律依据

◆ 核心规则：《公司法》第25条规定了决议不成立的情形。公司股东会、董事会的决议内容违反法律、行政法规的，股东可以请求人民法院确认决议不成立。

结合《最高人民法院关于适用〈中华人民共和国公司法〉若干问题的规定（四）》（以下简称《公司法司法解释四》），决议不成立的情形包括：

（二）决议不成立的具体情形

1. 未召开会议

公司未召开股东会、董事会会议，却形成了所谓的"决议"。这种情形下，决议不具备成立的基本要件，属于最严重的程序瑕疵。

典型情形：

  • 仅有部分股东签字，未实际召开会议；
  • 以书面传签方式替代会议，但不符合章程规定；
  • 董事会成员仅通过电话或微信沟通，未形成正式会议记录。

2. 未对决议事项进行表决

虽然召开了会议，但未对相关事项进行表决。例如：

  • 会议议程中未包含该决议事项；
  • 会议记录中无表决记载；
  • 以"一致同意"替代正式表决程序。

3. 出席人数或表决权不达标

出席会议的人数或股东所持表决权不符合法律或公司章程的规定。例如：

  • 有限公司股东会出席人数不足章程要求；
  • 股份公司股东大会出席股东所持股份不足法定比例。

4. 表决结果未达到法定或章程比例

表决结果未达到《公司法》或者公司章程规定的通过比例。例如：

  • 普通决议未达到出席会议的股东所持表决权过半数通过；
  • 特别决议未达到三分之二以上表决权通过。

（三）不成立的法律后果

◆ 决议不成立的法律后果：

  • 决议自始不存在，不产生任何法律效力；
  • 基于该决议实施的行为可能被认定为无效；
  • 任何利害关系人均可主张决议不成立；
  • 不受诉讼时效限制（确认之诉不适用诉讼时效）。

四、◆ 决议可撤销（第26条）

（一）法律依据

◆ 核心规则：《公司法》第26条规定了决议可撤销的情形。

（二）可撤销的具体情形

1. 召集程序违法或违反章程

  • 会议召集权人不符合法律规定（如应由董事会召集而由董事长个人召集）；
  • 会议通知未在法定或章程规定的时间内发出；
  • 通知未载明会议议题；
  • 未通知部分股东参加。

2. 表决方式违法或违反章程

  • 表决方式不符合章程规定（如应以投票方式表决而采用举手方式）；
  • 利害关系股东未回避表决；
  • 表决权计算错误。

3. 决议内容违反章程

  • 决议内容与公司章程的规定相冲突；
  • 超越章程规定的权限范围。

（三）起诉期限：60日

◆ 核心规则：《公司法》第26条第2款规定：

股东请求撤销股东会、董事会决议的，应当自决议作出之日起六十日内提起诉讼。

▲ 60日期限的性质：这是除斥期间，不适用中止、中断的规定。超过60日未起诉的，决议确定有效，股东丧失撤销权。

期限起算：自决议作出之日起算，而非自股东知道或应当知道决议之日起算。这意味着即使股东在60日后才知道决议的存在，也不能再提起撤销之诉。

五、◆ 决议无效（第25条）

（一）法律依据

◆ 核心规则：《公司法》第25条规定，公司股东会、董事会的决议内容违反法律、行政法规的，股东可以请求人民法院确认决议无效。

（二）决议无效的具体情形

决议无效是指决议内容违反法律、行政法规的强制性规定。典型情形包括：

  • 决议内容违反《公司法》的强制性规定（如违法分配利润、违法减资）；
  • 决议内容违反其他法律的强制性规定（如违法为股东提供财务资助）；
  • 决议内容损害社会公共利益；
  • 决议内容违反公序良俗。

（三）无效的法律后果

  • 决议自始无效；
  • 任何利害关系人均可主张决议无效；
  • 不受诉讼时效限制；
  • 基于无效决议实施的行为可能被撤销或确认无效。

六、三者的对比与衔接

（一）不成立 vs 无效 vs 可撤销

（二）瑕疵程度的递进关系

◆ 瑕疵程度的递进关系：

决议不成立 > 决议无效 > 决议可撤销

  • 不成立：决议不具备成立的基本要件（未召开会议、未表决等），瑕疵最为严重；
  • 无效：决议虽然成立，但内容违反法律强制性规定，瑕疵严重；
  • 可撤销：决议成立且内容合法，但程序或内容违反章程，瑕疵较轻。

▲ 实务区分：在具体案件中，需要准确判断瑕疵的类型和程度，选择正确的诉讼请求。错误选择诉讼请求可能导致败诉。

七、▲ 实务操作指引

（一）提起决议效力之诉的主体

诉讼类型 适格主体 法律依据
确认不成立 股东、董事、监事等利害关系人 《公司法》第25条
确认无效 股东、董事、监事等利害关系人 《公司法》第25条
请求撤销 股东（限股东） 《公司法》第26条

▲ 注意：撤销之诉的适格主体仅限于股东，董事、监事等不能提起撤销之诉。

（二）举证责任分配

1. 原告的举证责任

  • 证明决议存在瑕疵的事实；
  • 证明其具有诉讼主体资格（如股东身份）；
  • 撤销之诉还需证明在60日内提起诉讼。

2. 被告的举证责任

  • 证明决议程序合法；
  • 证明决议内容合法；
  • 证明原告已超过起诉期限（撤销之诉）。

（三）诉讼时效与除斥期间

诉讼类型 时间限制 性质 起算点
确认不成立 无 诉讼时效不适用 -
确认无效 无 诉讼时效不适用 -
请求撤销 60日 除斥期间 决议作出之日

（四）决议被撤销/无效后的法律后果

1. 对公司的效力

  • 决议自始无效或被撤销后，基于该决议实施的行为失去法律基础；
  • 公司应当恢复原状或赔偿损失。

2. 对第三人的效力

  • 善意第三人基于决议实施的行为受保护（详见下文第八部分）；
  • 非善意第三人不受保护。

3. 内部追责

  • 有过错的董事、高管可能承担赔偿责任；
  • 股东可能需要返还基于无效决议获得的利益。

八、善意相对人保护（第28条）

◆ 核心规则：《公司法》第28条规定：

股东会、董事会决议被人民法院确认无效或者撤销的，公司根据该决议与善意相对人形成的民事法律关系不受影响。

善意相对人的保护要件：

  1. 公司已根据决议与相对人形成了民事法律关系；
  2. 相对人在形成法律关系时不知道且不应当知道决议存在瑕疵；
  3. 相对人已尽到合理审查义务。

保护范围：

  • 善意相对人基于决议取得的权利不受影响；
  • 公司不得以决议被撤销或无效为由对抗善意相对人；
  • 公司因此遭受的损失，可向有过错的股东、董事追偿。

九、审查清单：如何判断决议效力

决议效力审查清单

  • [ ] 1. 决议是否成立

    • 是否实际召开了会议？
    • 是否对决议事项进行了表决？
    • 出席人数或表决权是否达标？
    • 表决结果是否达到法定或章程比例？

  • [ ] 2. 决议内容是否违法

    • 决议内容是否违反法律、行政法规的强制性规定？
    • 决议内容是否损害社会公共利益？
    • 决议内容是否违反公序良俗？

  • [ ] 3. 召集程序是否合法

    • 召集权人是否适格？
    • 通知是否在法定或章程期限内发出？
    • 通知是否载明会议议题？
    • 是否通知了所有有权参加的股东/董事？

  • [ ] 4. 表决方式是否合法

    • 表决方式是否符合章程规定？
    • 利害关系人是否回避？
    • 表决权计算是否正确？

  • [ ] 5. 决议内容是否违反章程

    • 决议事项是否在章程规定的权限范围内？
    • 决议内容是否与章程条款冲突？

  • [ ] 6. 是否已过起诉期限

    • 撤销之诉是否在60日内提起？
    • 不成立或无效之诉不受时间限制。

十、典型案例分析

案例一：未召开会议的决议不成立

基本案情：A公司股东甲、乙、丙三人，甲持有60%股权。甲在未通知乙、丙的情况下，自行制作了一份股东会决议，将公司主要资产转让给甲关联的B公司。乙、丙知情后诉请确认决议不成立。

争议焦点：未实际召开会议形成的"决议"是否成立？

分析结论：

  1. 股东会决议的成立以实际召开会议并进行表决为前提；
  2. 甲未通知乙、丙参加会议，也未实际召开会议；
  3. 仅有甲一人签字的"决议"不具备决议的基本构成要件；
  4. 结论：确认决议不成立。

实务要点：未实际召开会议形成的"决议"不具备决议的成立要件，应当认定为决议不成立。

案例二：违反通知程序的决议可撤销

基本案情：B公司召开股东会，会议通知仅提前3天发出（章程规定提前15天）。股东丁在会上对决议提出异议，但决议仍以多数票通过。丁在决议作出后30日内提起撤销之诉。

争议焦点：通知期限不足是否构成撤销事由？

分析结论：

  1. 会议通知期限属于章程规定的程序性要求；
  2. 通知期限不足影响了股东的准备时间和参与权；
  3. 该程序瑕疵属于"召集程序违反章程"的情形；
  4. 丁在60日内提起诉讼，符合起诉期限要求；
  5. 结论：撤销该股东会决议。

实务要点：会议通知期限不足属于召集程序违反章程，构成可撤销事由。股东在60日内起诉的，人民法院应当支持。

十一、总结

公司决议效力判断是公司法实务中的基础性问题。新《公司法》建立的"不成立—可撤销—无效"三层次体系，为司法实践提供了清晰的裁判框架。

核心要点：

  1. 决议不成立适用于最严重的程序瑕疵（未召开会议、未表决等）；
  2. 决议无效适用于内容违反法律、行政法规的情形；
  3. 决议可撤销适用于程序或内容违反章程的情形，受60日除斥期间限制；
  4. 善意相对人基于决议形成的法律关系不受决议被撤销或无效的影响；
  5. 准确判断瑕疵类型是选择正确诉讼请求的前提。
