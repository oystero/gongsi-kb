实务-对赌协议实务

实务专题 8199字 21 分钟阅读

一、问题引入：对赌协议的概念与实务背景

对赌协议（Valuation Adjustment Mechanism，VAM），又称估值调整协议，是投资方与融资方在达成股权融资协议时，为解决交易双方对目标公司未来发展的不确定性、信息不对称以及代理成本而设计的条款。其本质是一种附条件的合同履行安排——双方以目标公司未来的经营业绩或特定事件作为条件，约定相应的权利义务调整。

实务背景：在PE/VC股权投资中，投资方对目标公司的估值通常基于对未来盈利能力的预测。然而，未来充满不确定性：目标公司能否达到预期业绩？能否如期上市？管理团队能否兑现承诺？对赌协议正是为解决这些不确定性而生的商业工具。它将投资方的风险部分转移给融资方，同时给予融资方获取更高估值的机会，实现风险与收益的再平衡。

争议焦点：对赌协议虽然是商业实践中的常见安排，但在司法实践中引发了大量争议，核心问题集中在两个层面：其一，对赌协议的效力如何认定？其二，即使有效，对赌条款的实际履行是否受到公司法资本制度的限制？这些问题涉及合同法的意思自治原则与公司法的资本维持原则之间的深层冲突。

二、对赌协议的类型

（一）业绩补偿型

典型条款：如目标公司在约定期限内未达到约定的业绩指标（如净利润、营业收入等），则融资方（目标公司股东或目标公司）向投资方支付现金补偿。

计算公式示例：

补偿金额 = 投资总额 x（1 - 实际净利润 / 承诺净利润）

实务特征：业绩补偿型对赌是最常见的对赌形式，通常以年度净利润为核心指标，辅以营业收入、用户增长等辅助指标。其特点是触发频率高、争议点多集中在业绩数据的审计与确认上。

（二）股权回购型

典型条款：如目标公司在约定期限内未完成约定目标（如上市、业绩指标等），则融资方以约定价格回购投资方持有的股权。

回购价格通常包括：

  • 投资本金；
  • 固定收益（通常按年化8%-15%计算）；
  • 已宣告但未支付的利润。

实务特征：股权回购型对赌通常在投资协议签署时即约定明确的回购价格公式，争议主要集中在回购条件是否成就以及回购义务的履行主体上。

（三）现金补偿 + 股权回购复合型

实务中最常见的是将业绩补偿与股权回购结合的复合型对赌条款。典型结构如下：

  • 第一阶段：未达业绩指标时，股东支付现金补偿；
  • 第二阶段：连续未达标或未在约定期限内上市时，触发股权回购；
  • 第三阶段：回购义务人无力回购时，触发担保条款或优先清算权。

三、◆ 对赌主体的区分——效力认定的关键

◆ 核心规则：对赌协议的效力认定，首先取决于对赌主体的不同。这是整个对赌协议法律分析的起点。

（一）投资方与目标公司对赌——效力争议焦点

投资方与目标公司对赌是效力争议的核心。这种对赌模式的根本问题在于：

  • 目标公司回购股权或支付现金补偿，本质上是公司向股东返还资本；
  • 这直接触及公司法的资本维持原则——公司资本是债权人利益的基本保障；
  • 可能构成抽逃出资，损害公司及其他股东的合法权益。

效力认定的关键区分：对赌协议本身的效力与对赌条款的可履行性应当分开评价。协议有效不等于条款可以履行。即使法院认定对赌协议有效，投资方要求实际履行时，仍需证明履行行为符合公司法关于减资、利润分配等强制性规定。

（二）投资方与股东/实际控制人对赌——原则上有效

◆ 核心规则：投资方与目标公司股东或实际控制人之间的对赌协议，原则上有效。

法理基础：

  • 股东之间的对赌安排属于合同自由的范畴；
  • 不涉及公司资产的直接减少，不违反资本维持原则；
  • 不损害公司债权人利益——债权人信赖的是公司资本，而非股东之间的私人安排；
  • 与 股东权利 的处分权能一致——股东有权处分自己的财产权益。

例外情形：

  • 存在欺诈、胁迫等合同无效事由（《民法典》第148-154条）；
  • 恶意串通损害第三人利益；
  • 违反法律、行政法规的效力性强制性规定。

（三）最高人民法院裁判立场的演变

阶段 代表案例 裁判立场 核心逻辑
2012年 海富案（最高法） 与公司对赌无效，与股东对赌有效 一刀切：与公司对赌=损害债权人
2019年 华工案（江苏高院） 与公司对赌有效且可履行 区分效力与可履行性
2019年11月 《九民纪要》第5条 与公司对赌不当然无效，但需审查履行 确立"效力/履行二分法"
2024年7月后 新公司法施行 资本维持原则强化，履行审查更严 减资程序要求更严格

四、法律框架

（一）《九民纪要》第5条——对赌协议效力的基本规则

◆ 核心规则：2019年《全国法院民商事审判工作会议纪要》（法〔2019〕254号）第5条对对赌协议的效力作出了系统规定，是当前审理对赌纠纷的基本依据。

1. 与股东对赌：投资方与目标公司的股东或者实际控制人订立的"对赌协议"，如无其他无效事由，认定有效。

2. 与公司对赌：投资方与目标公司订立的"对赌协议"在不存在法定无效事由的情况下，目标公司仅以存在股权回购或者金钱补偿约定为由，主张"对赌协议"无效的，人民法院不予支持。

3. 履行审查：投资方主张实际履行的，人民法院应当审查是否符合公司法关于"股东不得抽逃出资"及股份回购的强制性规定，判决是否支持其诉讼请求。

◆ 核心要义：《九民纪要》确立了"效力与履行二分法"——合同效力问题适用合同法（民法典），合同履行问题适用公司法。这一立场纠正了海富案的简单化处理，为对赌协议的效力认定提供了更为精细的分析框架。

（二）新《公司法》对资本维持原则的强化

2024年7月1日施行的新《公司法》（2023年12月29日修订）在以下方面强化了资本维持原则，直接影响对赌协议的可履行性：

1. 限期认缴制（第47条）：

  • 有限公司股东认缴的出资额应当自公司成立之日起五年内缴足；
  • 这限制了通过高额认缴稀释债权人保护的做法，也间接影响对赌回购后公司的资本充足性。详见 公司的设立。

2. 减资程序（第224条）：

  • 公司减少注册资本，应当编制资产负债表及财产清单；
  • 应当自作出减资决议之日起十日内通知债权人，并于三十日内在报纸上或者国家企业信用信息公示系统公告；
  • 债权人有权自接到通知之日起三十日内，未接到通知的自公告之日起四十五日内，要求公司清偿债务或者提供相应的担保；
  • 详见 公司重大变更。

3. 利润分配规则（第210条）：

  • 公司弥补亏损和提取公积金后所余税后利润才能向股东分配；
  • 这直接限制了以利润分配方式履行对赌义务——如果公司无可分配利润，现金补偿义务将无法通过利润分配路径履行。

4. 股份回购的法定情形（第162条）：

  • 新《公司法》明确了股份有限公司回购自身股份的法定情形；
  • 对赌回购不属于法定回购情形，需要通过减资程序实现。

（三）减资程序与对赌回购的结构性冲突

▲ 实务重难点：当对赌回购义务人为目标公司时，回购的实现通常需要通过减资程序，但减资程序与对赌回购之间存在结构性冲突：

冲突维度 减资程序要求 对赌回购需求 实务障碍
决议机制 须经股东会三分之二以上表决权通过 回购义务人可能仅为部分股东 其他股东可能不同意减资
债权人保护 债权人有权要求清偿或担保 公司可能无力清偿全部债务 债权人异议可能阻断减资
时间周期 公告期+债权人异议期，至少75天 对赌回购通常有明确期限 程序耗时可能导致违约

五、▲ 对赌协议的效力分析

（一）与股东对赌：原则上有效

◆ 核心规则：投资方与目标公司股东之间的对赌协议，如无其他无效事由，应当认定有效。这一立场在海富案中即已确立，并被《九民纪要》所确认。

效力基础的法理分析：

  • 属于股东之间的合同安排，适用合同法的一般规则；
  • 不违反法律、行政法规的效力性强制性规定；
  • 不涉及公司资产的直接减少，不影响公司的资本充实；
  • 属于当事人意思自治的范畴——股东有权处分自己的财产权益；
  • 与 股东权利 的处分权能一致。

需要警惕的例外情形：

  • 对赌协议存在显失公平或乘人之危的情形，可能被撤销；
  • 股东利用对赌协议转移公司资产、逃避债务，可能被认定为恶意串通；
  • 对赌协议的实质是为股东抽逃出资提供通道。

（二）与公司对赌：合同效力与合同履行分开评价

▲ 实务重难点：投资方与目标公司对赌的效力分析，需要严格区分效力层面和履行层面：

1. 效力层面——协议原则上有效

根据《九民纪要》第5条，投资方与目标公司订立的对赌协议，不存在法定无效事由的，应当认定有效。理由在于：

  • 对赌协议本身不违反法律、行政法规的效力性强制性规定；
  • 合同法（《民法典》）尊重当事人的意思自治；
  • 不能仅因合同涉及公司即否定其效力。

2. 履行层面——需符合公司法强制性规定

◆ 即使协议有效，条款的履行仍须审查是否符合公司法的强制性规定：

  • 股权回购的履行：需通过减资程序（第224条）或法定股份回购情形（第162条）实现；
  • 现金补偿的履行：需符合利润分配规则（第210条），公司必须有可分配利润；
  • 违反资本维持原则的后果：即使协议有效，法院也不能判决公司违反资本维持原则履行对赌义务。

（三）回购条款的可履行性分析

履行路径 适用条件 法律依据 实务难度
减资回购 公司有足够净资产，能完成减资程序 《公司法》第224条 高（股东会决议+债权人保护+工商变更）
利润分配抵扣 公司有足够可分配利润 《公司法》第210条 中（受利润分配限制，金额受限）
法定股份回购 符合《公司法》规定的法定回购情形 《公司法》第162条 低（但法定情形有限，对赌回购通常不在此列）
股东担保履行 股东提供连带责任担保 合同约定 较低（取决于股东偿付能力）

六、▲ 实务审查要点

（一）对赌条款的设置技巧

1. 对赌主体的选择——优先与股东/实际控制人对赌

  • 优先选择与股东或实际控制人对赌，可有效规避资本维持原则的限制；
  • 与公司对赌时，需额外关注可履行性问题，建议同时要求股东提供连带责任担保；
  • 可设置多层对赌结构：先由股东承担第一顺位回购义务，公司承担补充义务。

2. 对赌指标的设定——合理、可量化、可审计

  • 业绩指标应当合理——既不能过高导致必然触发，也不能过低失去约束意义；
  • 指标应当可量化——避免使用"重大进展""显著提升"等模糊表述；
  • 指标应当可审计——明确计算口径、审计标准、审计机构的选任规则；
  • 与 公司设立 时的出资评估相呼应，确保估值基础的合理性。

（二）回购触发条件的明确性

▲ 回购触发条件应当明确、具体、可操作——模糊的触发条件是诉讼的主要来源：

  • 上市目标：明确上市的交易所（如上交所、深交所、港交所）、板块（如主板、科创板、创业板）、时间期限（如"投资完成后36个月内"）；
  • 业绩目标：明确净利润、营业收入等具体指标的数值、计算口径、审计基准；
  • 其他触发条件：如重大违约、控制权变更、核心团队离职等，需逐一明确界定标准。

常见争议：

  • 触发条件约定不明导致双方各执一词；
  • 多个触发条件之间的关系（并列/递进/选择）不清；
  • 触发条件的成就与否难以举证，尤其是业绩数据的争议。

（三）回购价格的确定方式

定价方式 计算公式 优点 缺点
固定收益型 本金 + 年化固定收益 x 年数 简单明确，易于执行 可能不公平，不反映公司实际价值
估值调整型 按约定估值公式计算 公平合理，反映公司变化 计算复杂，易生争议
市场定价型 按届时公允价值确定 接近市场真实价值 公允价值难以确定，易生纠纷
就高型 取上述方式中的较高者 保护投资方利益 对融资方不利，可能显失公平

（四）与公司对赌时的减资可行性评估

▲ 在设计与公司对赌的回购条款时，必须事前评估减资的可行性：

  • 公司是否具有足够的净资产以覆盖回购价格；
  • 公司是否有大额未清偿债务，债权人可能提出异议；
  • 其他股东的配合度——是否可能在股东会上投反对票；
  • 公司所处行业的监管要求——某些行业的减资可能受到特殊限制；
  • 建议在投资协议中要求目标公司事先出具股东会决议，预授权减资程序。

（五）争议解决条款的设计

  • 仲裁 vs 诉讼：仲裁保密性好、效率高，但对案外人（如公司其他股东）无约束力；诉讼透明度高、可上诉，但周期较长；
  • 管辖约定：明确约定管辖法院或仲裁机构；
  • 保全措施：约定触发回购后投资方有权申请财产保全；
  • 送达条款：约定有效的送达地址和送达方式。

七、风险提示

（一）公司利润不足时的分配限制

▲ 如果目标公司没有足够的可分配利润，以利润分配方式履行对赌义务将受到实质限制：

  • 公司必须先弥补亏损、提取法定公积金，之后的税后利润才能分配（《公司法》第210条）；
  • 公司不得以资本金或资本公积金进行利润分配；
  • 投资方可能面临"胜诉但无法执行"的困境——法院判决公司支付补偿，但公司无可分配利润。

（二）减资程序的不确定性

▲ 减资程序面临多重不确定性，是与公司对赌回购的最大风险：

  • 其他股东可能不同意减资决议——减资须经三分之二以上表决权通过（第224条），控股股东可能反对；
  • 债权人可能要求提前清偿债务或提供担保——公司可能无力应对；
  • 减资程序耗时较长——公告期加债权人异议期至少75天，可能超过对赌约定的回购期限；
  • 工商部门可能对减资申请进行实质审查，增加程序不确定性。

（三）诉讼时效问题

▲ 对赌纠纷的诉讼时效起算点存在争议，是容易被忽视的风险：

  • 约定了明确履行期限的，自期限届满之日起算（3年）；
  • 未约定期限的，自权利人知道或应当知道权利受到损害之日起算；
  • 持续性对赌义务（如逐年业绩补偿）的诉讼时效逐笔起算；
  • 投资方应当及时主张权利，避免因时效届满丧失胜诉权。

（四）对赌期限的合理设定

▲ 对赌期限的设定直接影响各方利益：

  • 期限过短：目标公司可能无法充分发展，对赌触发概率过高；
  • 期限过长：投资方资金占用成本增加，退出预期不确定；
  • 建议根据目标公司的行业特征、发展阶段、上市计划合理设定；
  • 可设置分阶段对赌，逐步调整估值和退出条件。

八、典型案例

（一）海富案（最高人民法院，2012年）

案件背景：投资方海富公司与目标公司世恒公司及其股东签订对赌协议，约定如世恒公司2008年净利润未达3000万元，世恒公司应予补偿。

最高人民法院裁判（(2012)民提字第11号）：

案例来源：君合律所

  • 与目标公司对赌：无效。“这一约定使得海富公司的投资可以取得相对固定的收益，该收益脱离了世恒公司的经营业绩，损害了公司利益和公司债权人利益”；
  • 与股东对赌：有效。“股东之间的对赌协议属于股东之间的合意，不损害公司及债权人利益”。

裁判意义：确立了"与公司对赌无效、与股东对赌有效"的二元裁判规则，但该规则过于简单化，未区分合同效力与合同履行，受到学界广泛批评。

（二）华工案（江苏省高级人民法院，2019年）

案件背景：投资方华工公司与目标公司扬锻公司签订对赌协议，约定如扬锻公司未在约定期限内上市，扬锻公司应以约定价格回购华工公司持有的股权。

江苏高院裁判（(2019)苏民再62号）：

案例来源：讼也

  • 对赌协议有效：不存在法定无效事由，不能仅以涉及公司即否定效力；
  • 回购条款可以履行：扬锻公司具有足够的净资产进行回购，回购不会导致公司资本不足；
  • 不违反资本维持原则：回购价格合理，不会损害公司债权人利益。

裁判意义：纠正了海富案的简单化立场，区分了对赌协议的效力与可履行性，为《九民纪要》的制定提供了实践基础。

（三）《九民纪要》后的最新裁判趋势

《九民纪要》确立的裁判框架：

  1. 对赌协议的效力与可履行性应当区分判断；
  2. 与公司对赌不当然无效，但需审查是否违反公司法的强制性规定；
  3. 回购条款的履行需符合减资程序或利润分配规则；
  4. 不能以协议有效为由直接判决公司履行违反资本维持原则的义务。

新《公司法》实施后的裁判趋势（2024年7月后）：

  • 资本维持原则进一步强化，法院对对赌回购的可履行性审查更加审慎；
  • 减资程序要求更为严格，法院倾向于要求投资方先完成减资程序再主张回购；
  • 对公司债权人的保护力度加大，债权人利益成为重要的审查因素；
  • 与股东对赌的效力认定保持稳定，意思自治原则得到尊重。

九、总结建议

（一）对赌协议设计的核心原则

1. 主体选择原则

  • 优先选择与股东或实际控制人对赌——这是最安全、最可执行的方案；
  • 与公司对赌时，必须充分评估可履行性，并要求股东提供连带责任担保；
  • 可设置多层对赌结构，实现风险分担。

2. 条款设计原则

  • 对赌指标应当合理、可量化、可审计——模糊的指标是争议的根源；
  • 回购触发条件应当明确、具体、避免歧义；
  • 回购价格应当公平合理，兼顾双方利益；
  • 约定明确的争议解决机制和送达条款。

3. 风险防范原则

  • 在投资协议中要求股东提供连带责任担保，确保即使公司无法履行，投资方仍可向股东追偿；
  • 约定对赌义务的优先受偿权和财产保全措施；
  • 设置分阶段的对赌条款，降低单次触发的风险敞口。

（二）对赌纠纷的诉讼策略

投资方（原告）策略：

  • 区分确认之诉与给付之诉——先确认对赌协议效力，再主张履行；
  • 与公司对赌时，可同时起诉公司和股东，增加获偿可能性；
  • 及时申请财产保全，防止被告转移资产；
  • 注意诉讼时效，避免因时效届满丧失胜诉权。

目标公司/股东（被告）策略：

  • 审查对赌协议是否存在法定无效事由；
  • 主张对赌条件未成就——围绕业绩数据、审计报告等展开举证；
  • 与公司对赌时，主张回购条款违反资本维持原则，无法实际履行；
  • 主张原告已超过诉讼时效。

核心要点：

  1. 对赌协议是PE/VC投资的核心条款，效力认定需区分主体——与股东对赌原则上有效，与公司对赌需审查可履行性；
  2. 《九民纪要》确立了"效力与履行二分法"，对赌协议有效不等于条款可以履行；
  3. 新《公司法》强化了资本维持原则，与公司对赌回购的履行面临更严格的限制；
  4. 减资程序是与公司对赌回购的主要履行路径，但程序复杂、不确定性高、耗时长；
  5. 对赌条款的设计应当明确、合理、可操作，并充分评估可履行性。
