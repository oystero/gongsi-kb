二、公司法概述

（一）立法目的

《公司法》第1条规定：“为了规范公司的组织和行为，保护公司、股东和债权人的合法权益，维护社会经济秩序，促进社会主义市场经济的发展，根据宪法，制定本法。”

◆ 核心目的：

  1. 规范公司组织和行为：确立公司设立、运营、变更、终止的基本规则
  2. 保护合法权益：平衡公司、股东、债权人三方利益
  3. 维护经济秩序：保障交易安全和市场稳定
  4. 促进经济发展：鼓励投资创业，优化营商环境

（二）调整对象

《公司法》第2条规定：“本法所称公司是指依照本法在中国境内设立的有限责任公司和股份有限公司。”

调整范围：

  • 组织关系：公司的设立、变更、终止
  • 行为关系：公司的经营、管理、对外交易
  • 内部关系：股东之间、股东与公司之间、公司与管理层之间
  • 外部关系：公司与债权人、公司与政府监管部门之间

（三）适用范围

适用范围 具体内容
空间效力 中国境内设立的公司
主体效力 有限责任公司、股份有限公司
时间效力 2024年7月1日起施行
特别法优先 外商投资、国有企业等另有规定的，优先适用特别法

三、2024年新公司法修订重大变化

（一）注册资本制度变革

◆ 重大变化：

  1. 5年实缴制：有限责任公司股东认缴的出资额应当自公司成立之日起五年内缴足（《公司法》第47条）
  2. 股份公司发起人实缴：发起人应当在公司成立前按照其认购的股份缴纳全部股款（《公司法》第96条）
  3. 出资加速到期：公司不能清偿到期债务时，公司或者已到期债权的债权人有权要求已认缴出资但未届出资期限的股东提前缴纳出资（《公司法》第54条）

（二）公司治理结构优化

变化内容 旧法规定 新法规定
监事会设置 必须设立监事会 可以选择设立监事会或审计委员会（第69条、第121条）
审计委员会 无明确规定 可以在董事会中设立审计委员会行使监事会职权
法定代表人 由董事长、执行董事或经理担任 可以由代表公司执行公司事务的董事或者经理担任（第10条）
董事会职权 列举式规定 更加灵活，公司章程可自主规定

（三）强化控股股东和实际控制人责任

◆ 新增规定：

  1. 事实董事责任：控股股东、实际控制人不担任公司董事但实际执行公司事务的，适用董事忠实义务和勤勉义务的规定（第180条）
  2. 影子董事责任：控股股东、实际控制人指示董事、高级管理人员从事损害公司或者股东利益的行为的，与该董事、高级管理人员承担连带责任（第192条）
  3. 横向人格否认：股东利用其控制的两个以上公司实施逃避债务行为的，各公司应当对任一公司的债务承担连带责任（第23条）

（四）国家出资公司专章

▲ 实务重点：

  1. 专章规定：设立"国家出资公司组织机构的特别规定"专章（第七章）
  2. 适用范围：国有独资公司、国有资本控股公司
  3. 治理特殊性：党组织领导作用、外部董事制度、审计委员会
  4. 出资人职责：明确履行出资人职责的机构及其权限

（五）其他重要变化

变化领域 主要内容
简易注销 增加简易注销制度（第240条）
强制注销 增加强制注销制度（第241条）
电子化 允许电子营业执照、电子会议、电子签名

四、公司法的基本原则

（一）有限责任原则

《公司法》第3条规定：“公司是企业法人，有独立的法人财产，享有法人财产权。公司以其全部财产对公司的债务承担责任。有限责任公司的股东以其认缴的出资额为限对公司承担责任；股份有限公司的股东以其认购的股份为限对公司承担责任。”

◆ 核心内涵：

  1. 股东有限责任：股东仅以其出资额或认购股份为限对公司负责
  2. 公司独立责任：公司以其全部财产对债务负责
  3. 责任隔离：股东个人财产与公司财产相互独立

▲ 例外情形：

  • 股东滥用有限责任，损害债权人利益，适用法人人格否认
  • 一人有限责任公司股东不能证明公司财产独立于股东自己的财产的，应当对公司债务承担连带责任

（二）法人人格独立原则

法人资格的取得：依法设立、有自己的名称、组织机构、住所、财产或者经费（《民法典》第58条）

独立性的表现：

  1. 财产独立：公司财产与股东财产分离
  2. 意志独立：公司意志通过股东会、董事会等机构形成
  3. 责任独立：公司独立承担民事责任
  4. 诉讼主体独立：公司可以以自己的名义起诉、应诉

（三）股东平等原则

《公司法》第4条规定：“公司股东依法享有资产收益、参与重大决策和选择管理者等权利。”

平等原则的体现：

  1. 同股同权：同类别的每一股份应当具有同等权利（第144条）
  2. 按比例行使权利：股东按照出资比例或持股比例行使表决权、分红权等
  3. 禁止不正当关联交易：控股股东不得利用关联关系损害公司利益

（四）资本维持原则

▲ 资本维持的具体要求：

  1. 不得抽逃出资：股东不得抽逃出资（第53条）
  2. 不得低于面值发行股份：股份公司不得折价发行股份（第148条）
  3. 利润分配限制：公司弥补亏损和提取公积金后所余税后利润方可分配（第214条）
  4. 股份回购限制：原则上公司不得收购本公司股份，法定例外除外（第162条）
  5. 减资程序严格：公司减资必须编制资产负债表、通知债权人、公告等（第224条）

七、学习建议

（一）学习方法

  1. 体系化学习：按照公司设立→运营→变更→终止的生命周期顺序学习
  2. 对比学习：有限公司与股份公司对比、新法与旧法对比
  3. 案例学习：结合经典案例理解法律规定
  4. 重点突破：抓住新公司法修订的重点内容

（二）实务高频问题

▲ 公司法实务中的高频问题：

  1. 法人人格否认制度（第23条）
  2. 注册资本5年实缴制（第47条）
  3. 出资加速到期（第54条）
  4. 股东权利保护（知情权、分红权、回购请求权）
  5. 董事忠实义务和勤勉义务（第180-182条）
  6. 股权转让规则（第84条、第157条）
  7. 公司解散与清算（第228-240条）
  8. 公司类型的实务选择（有限公司vs股份公司的区别）
  9. 公司的担保能力（第15条、越权担保）

（三）实务应用

  1. 公司设立：选择公司类型、制定章程、确定出资方式
  2. 公司治理：股东会、董事会、监事会的设置与运行
  3. 股权转让：股权转让协议、优先购买权、股权交割
  4. 公司纠纷：股东资格确认、利润分配、公司僵局处理
