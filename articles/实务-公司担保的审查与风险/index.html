实务-公司担保的审查与风险

实务专题 3533字 9 分钟阅读

一、问题引入：公司对外担保为何是高频纠纷领域

公司对外担保是商事交易中最常见的增信方式之一，也是司法实务中纠纷最为集中的领域之一。其高频争议的核心原因在于：公司对外担保涉及公司意思表示的形成、法定代表人权限的边界、相对人合理信赖的保护等多重法律关系的交织。

在实践中，大量担保纠纷源于以下场景：

  • 法定代表人未经公司决议擅自对外提供担保；
  • 公司章程对担保设有限制，但相对人未予审查；
  • 关联担保中未执行回避表决程序；
  • 上市公司对外担保未履行信息披露义务。

这些问题的实质是：当公司内部治理程序存在瑕疵时，对外担保合同的效力如何认定？ 这需要在公司自治、交易安全与善意保护之间寻求平衡。

二、法律框架

（一）《公司法》第15条：公司对外担保的决议程序

◆ 核心规则：2024年新《公司法》第15条（原《公司法》第16条）确立了公司对外担保的基本决议程序框架，是判断担保效力的核心法律依据。

1. 一般担保

公司向其他企业投资或者为他人提供担保，按照公司章程的规定，由董事会或者股东会决议。这意味着：

  • 决议机关的授权来源是公司章程，而非法律的直接规定；
  • 公司可以选择由董事会或股东会作为决议机关；
  • 如果章程未明确规定，则应由股东会决议（重大事项原则）。

2. 关联担保（为股东或实际控制人提供担保）

◆ 核心规则：公司为公司股东或者实际控制人提供担保的，必须经股东会决议。这是法律的强制性规定，公司章程不得降低为董事会决议。

关联担保的特殊要求：

  • 决议机关：必须是股东会，不得由董事会决议替代；
  • 回避表决：受担保的股东或者受实际控制人支配的股东，不得参加该事项的表决；
  • 表决通过：该项表决由出席会议的其他股东所持表决权的过半数通过。

3. 上市公司对外担保的特别规定

上市公司对外担保受到更为严格的监管：

  • 须遵守证券交易所的上市规则中关于担保的特别规定；
  • 必须及时履行信息披露义务；
  • 对外担保总额不得超过公司净资产的一定比例（交易所规则）；
  • 为控股股东、实际控制人及其关联方提供担保受到严格限制。

（二）《民法典》第504条：法定代表人越权代表

◆ 核心规则：法人的法定代表人或者非法人组织的负责人超越权限订立的合同，除相对人知道或者应当知道其超越权限外，该代表行为有效，订立的合同对法人或者非法人组织发生效力。

这一条文将越权担保的效力问题转化为相对人善意与否的判断：

  • 相对人善意 → 担保合同对公司发生效力；
  • 相对人非善意 → 担保合同对公司不发生效力。

三、善意相对人保护

（一）善意的认定标准

◆ 核心规则：根据《最高人民法院关于适用〈中华人民共和国民法典〉有关担保制度的解释》（以下简称《担保制度解释》），善意相对人的认定标准为：

相对人在订立担保合同时不知道且不应当知道法定代表人超越权限。相对人有证据证明已对公司决议进行了合理审查，人民法院应当认定其构成善意，但公司有证据证明相对人知道或者应当知道决议系伪造、变造的除外。

"合理审查"的内涵：

  • 形式审查：审查是否有决议文件、决议机关是否正确、签章是否齐全；
  • 不要求实质审查：不要求相对人核实决议的真实性、签名的真伪；
  • 不要求审查公司章程：不要求相对人审查公司章程对担保的具体限制。

（二）未审查公司决议是否影响合同效力

▲ 实务重难点：司法实践中，最高人民法院的裁判立场经历了一定演变：

阶段 裁判立场 代表案例
早期 未审查决议不影响合同效力 部分地方法院裁判
中期 应当审查决议，未审查则非善意 2019年《九民纪要》
现行 合理审查即可，不要求实质审查 《担保制度解释》

现行裁判规则：

  • 相对人未审查公司决议的，原则上不构成善意；
  • 但存在例外情形（如一人公司、公司公开表示担保等）；
  • 善意的举证责任在相对人一方。

四、▲ 审查清单

在审查公司对外担保合同时，应逐项核查以下内容：

审查清单

  • [ ] 1. 公司章程对担保的限制

    • 章程是否规定了担保的决议机关（董事会or股东会）；
    • 章程是否对担保金额设置了上限；
    • 章程是否禁止或限制特定类型的担保。

  • [ ] 2. 担保决议的类型

    • 一般担保：核查是否取得了董事会或股东会决议（依章程规定）；
    • 关联担保：必须核查股东会决议，董事会决议不足。

  • [ ] 3. 表决程序是否合法

    • 会议通知是否依法发出；
    • 出席会议的人数是否达到法定或章程要求；
    • 表决权比例是否达标；
    • 关联担保中关联股东是否回避。

  • [ ] 4. 是否涉及关联交易

    • 被担保方是否为公司股东或实际控制人；
    • 被担保方是否与公司存在其他关联关系；
    • 是否需要适用关联交易的特别审查程序。

  • [ ] 5. 上市公司对外担保的信息披露

    • 是否已发布担保公告；
    • 公告内容是否与担保合同一致；
    • 是否符合交易所上市规则的要求。

  • [ ] 6. 担保金额是否超过章程限额

    • 担保金额与公司章程规定的限额比较；
    • 累计担保金额是否超过公司净资产的法定比例。

五、风险提示

（一）未审查决议的后果

▲ 如果相对人在接受公司担保时未审查公司决议文件：

  • 公司可以主张法定代表人越权代表，担保对公司不发生效力；
  • 相对人将承担举证不能的不利后果；
  • 即使担保合同已经签署，也可能被认定为无效或不对公司发生效力。

（二）公司内部限制不能对抗善意相对人

◆ 公司章程对担保的内部限制（如金额限制、类型限制），如果相对人已经尽到合理审查义务：

  • 公司不得以内部限制对抗善意相对人；
  • 担保合同对公司发生效力；
  • 公司承担担保责任后，可向有过错的法定代表人追偿。

（三）上市公司对外担保的合规风险

▲ 上市公司对外担保的风险更为复杂：

  • 未履行信息披露义务的担保可能被认定为无效；
  • 监管机构可能对公司及相关责任人进行行政处罚；
  • 可能引发证券虚假陈述责任。

六、典型案例分析

案例：某投资公司诉某科技公司担保合同纠纷

基本案情：甲公司（投资公司）向乙公司（科技公司）的关联企业提供借款，乙公司法定代表人张某以公司名义签署担保合同。乙公司章程规定对外担保须经股东会决议，但张某未经股东会决议即签署担保合同。后借款到期未还，甲公司诉请乙公司承担担保责任。

争议焦点：未经股东会决议的担保合同是否对乙公司发生效力？

分析结论：

  1. 张某作为法定代表人，其以公司名义签署担保合同属于代表行为；
  2. 该代表行为超越了公司章程赋予的权限，构成越权代表；
  3. 甲公司作为专业投资机构，有能力也有义务审查乙公司的股东会决议；
  4. 甲公司未审查股东会决议，不构成善意相对人；
  5. 结论：担保合同对乙公司不发生效力。

实务要点：相对人在接受公司担保时，应当审查公司决议文件。未审查决议的，不构成善意，担保对公司不发生效力。

参考案例：（2012）民提字第156号（招商银行大连东港支行诉大连振邦集团有限公司担保合同纠纷案）。

七、实务操作建议（合同审查步骤）

第一步：确认担保类型

  • 区分一般担保与关联担保；
  • 确认被担保方与公司的关系。

第二步：要求提供公司决议文件

  • 一般担保：董事会决议或股东会决议（依章程）；
  • 关联担保：必须是股东会决议；
  • 审查决议文件的完整性（签名、盖章、日期等）。

第三步：审查决议的合法性

  • 会议通知是否合法；
  • 出席人数是否达标；
  • 表决比例是否达标；
  • 关联股东是否回避。

第四步：审查公司章程

  • 了解章程对担保的特别规定；
  • 确认担保金额是否在章程限额之内。

第五步：留存审查证据

  • 保留公司决议文件的复印件；
  • 保留审查过程的书面记录；
  • 如有疑问，书面函询公司确认。

第六步：上市公司特别审查

  • 核查是否已履行信息披露义务；
  • 核查是否符合交易所上市规则。

八、总结

公司对外担保的审查是商事法律实务中的核心技能。善意相对人的保护机制平衡了公司自治与交易安全，但相对人必须尽到合理审查义务。在实务操作中，审查公司决议文件是接受公司担保的必备步骤，遗漏此步骤将面临担保合同对公司不发生效力的重大风险。

核心要点：

  1. 一般担保依章程由董事会或股东会决议；
  2. 关联担保必须经股东会决议，关联股东回避；
  3. 相对人应当审查公司决议，否则不构成善意；
  4. 善意相对人受法律保护，公司内部限制不能对抗；
  5. 上市公司担保有额外的信息披露要求。
