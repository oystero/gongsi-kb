董事、监事、高级管理人员制度

二、核心制度详解

（一）董事制度

1. 董事的资格与选任

◆ 核心规则：根据《公司法》第59条，股东会行使选举和更换董事的职权。有限责任公司的董事由股东会选举产生；股份有限公司的董事由股东大会选举产生。

概念：

  • 董事是由公司股东会选举产生的，负责公司内部管理和对外经营决策的人员
  • 全体董事组成董事会，董事会是公司的日常经营决策机构

任职资格的消极条件（第146条）：

  • 无民事行为能力或者限制民事行为能力
  • 因贪污、贿赂、侵占财产、挪用财产或者破坏社会主义市场经济秩序，被判处刑罚，执行期满未逾五年；被宣告缓刑的，自缓刑考验期满之日起未逾二年
  • 因犯罪被剥夺政治权利，执行期满未逾五年；被宣告缓刑的，自缓刑考验期满之日起未逾二年
  • 担任破产清算的公司、企业的经理或者董事、厂长，对破产负有个人责任的，破产清算完结之日起未逾三年
  • 担任因违法被吊销营业执照、责令关闭的公司、企业的法定代表人，并负有个人责任的，被吊销营业执照、责令关闭之日起未逾三年
  • 个人所负数额较大的债务到期未清偿被人民法院列为失信被执行人

不适格董监高的处理方式：

  1. 违反规定选举、委派董事、监事或者聘任高级管理人员的，该选举、委派或者聘任无效
  2. 董事、监事、高级管理人员在任职期间出现不得担任董监高情形的，公司应当解除其职务

注意：新公司法取消了有限责任公司董事会人数上限，仅要求三人以上（第68条）。

2. 董事的任期与辞任

  • 董事任期由公司章程规定，每届任期不得超过三年，任期届满可以连选连任（第70条）
  • 董事辞任的，以公司收到辞任通知之日辞任生效；但在改选出的董事就任前，原董事仍应当依照法律、行政法规和公司章程的规定，履行董事职务

2.5 法定代表人

◆ 核心规则：法定代表人是依照法律或者公司章程的规定，代表公司从事民事活动的负责人。

法定代表人的要点：

  1. 法定代表人以公司名义从事的民事活动，其法律后果由公司承受
  2. 法定代表人依照公司章程的规定，由代表公司执行公司事务的董事或者经理担任
  3. 担任法定代表人的董事或者经理辞任的，视为同时辞去法定代表人
  4. 法定代表人辞任的，公司应当在法定代表人辞任之日起30日内确定新的法定代表人
  5. 公司法定代表人变更，应当办理变更登记，变更登记申请书由变更后的法定代表人签署

3. 董事会的组成、职权与议事规则

董事会的组成（第68条）：

  • 有限责任公司设董事会，成员为三人以上
  • 股东人数较少或者规模较小的有限责任公司，可以不设董事会，设一名董事（第75条）
  • 董事会设董事长一人，可以设副董事长

董事会的职权（第67条）：

职权类型 具体内容
召集权 召集股东会会议，并向股东会报告工作
执行权 执行股东会的决议
决策权 决定公司的经营计划和投资方案
方案权 制订公司年度财务预算方案、决算方案、利润分配方案、弥补亏损方案
方案权 制订公司增加或者减少注册资本、发行公司债券、合并、分立、解散或者变更公司形式的方案
人事权 决定公司内部管理机构的设置；决定聘任或者解聘公司经理及其报酬事项
制度权 制定公司的基本管理制度

议事规则（第68条、第73条）：

  • 董事会决议的表决，实行一人一票
  • 董事会决议的表决，应当有过半数的董事出席方可举行；董事会作出决议，必须经全体董事的过半数通过

4. ◆ 董事的忠实义务与勤勉义务

《公司法》第180条是新公司法的核心条款之一，首次以立法形式明确界定了忠实义务与勤勉义务的内涵：

忠实义务（第180条第1款）：

董事、监事、高级管理人员对公司负有忠实义务，应当采取措施避免自身利益与公司利益冲突，不得利用职权牟取不正当利益。

勤勉义务（第180条第2款）：

董事、监事、高级管理人员对公司负有勤勉义务，执行职务应当为公司的最大利益尽到管理者通常应有的合理注意。

▲ 实务重难点：忠实义务的核心是"避免利益冲突"，强调主观上的忠诚；勤勉义务的核心是"合理注意"，强调客观上的尽职。违反忠实义务的行为通常直接导致行为无效或可撤销，并可能触发归入权；违反勤勉义务则需以商业判断规则（Business Judgment Rule）为标准进行判断。

◆ 实质董事：公司的控股股东、实际控制人不担任公司董事但实际执行公司事务的，适用忠实义务和勤勉义务的规定。

5. 董事的禁止行为

《公司法》第181条明确列举了董事、监事、高级管理人员的禁止行为：

  1. 侵占公司财产、挪用公司资金
  2. 将公司资金以其个人名义或者以其他个人名义开立账户存储
  3. 利用职权贿赂或者收受其他非法收入
  4. 接受他人与公司交易的佣金归为己有
  5. 擅自披露公司秘密
  6. 违反对公司忠实义务的其他行为

注意：第181条的禁止行为为6项，知识库原列8项中第3、4、5项实际分别对应自我交易（第182条）、商业机会篡夺（第184条）、竞业禁止（第183条）的独立条款，非第181条内容。第181条新增"侵占公司财产"和"利用职权贿赂或者收受其他非法收入"两项。

6. 审计委员会制度

◆ 新公司法重大创新——《公司法》第69条：

有限责任公司可以按照公司章程的规定在董事会中设置由董事组成的审计委员会，行使本法规定的监事会的职权，不设监事会或者监事。

这一制度变革的意义：

  • 单层制治理模式的引入：公司可以选择"董事会+监事会"的传统双层制，也可以选择"董事会（含审计委员会）"的单层制
  • 审计委员会成员应当为三名以上，其中过半数成员不得在公司担任除董事以外的其他职务
  • 上市公司必须设置审计委员会（第136条）

（二）监事制度

1. 监事的资格与选任

  • 监事由股东会选举和更换（第59条）
  • 董事、高级管理人员不得兼任监事（第130条）
  • 监事的消极任职资格与董事相同

2. 监事会的组成与职权

组成（第130条）：

  • 有限责任公司设监事会，其成员不得少于三人
  • 股东人数较少或者规模较小的有限责任公司，可以不设监事会，设一至二名监事
  • 监事会应当包括股东代表和适当比例的公司职工代表，其中职工代表的比例不得低于三分之一

职权（第131条）：

  • 检查公司财务
  • 对董事、高级管理人员执行职务的行为进行监督
  • 当董事、高级管理人员的行为损害公司的利益时，要求董事、高级管理人员予以纠正
  • 提议召开临时股东会会议
  • 向股东会会议提出提案
  • 依照《公司法》第189条的规定，对董事、高级管理人员提起诉讼

3. 新公司法：监事会vs审计委员会的选择

比较维度 监事会 审计委员会
设置依据 第130条 第69条
组成 股东代表+职工代表（≥1/3） 董事组成（≥3人，过半数为外部董事）
模式 双层制 单层制
上市公司 可选 必须设置
行使职权 法定职权 代行监事会职权

（三）高级管理人员

范围（第217条）：

  • 经理、副经理
  • 财务负责人
  • 上市公司董事会秘书
  • 公司章程规定的其他人员

经理的职权（第74条）： 经理对董事会负责，行使下列职权：主持公司的生产经营管理工作，组织实施董事会决议；组织实施公司年度经营计划和投资方案；拟订公司内部管理机构设置方案；拟订公司的基本管理制度等。

（四）▲ 董事、高管的赔偿责任

1. 对公司的赔偿责任

《公司法》第188条：

董事、监事、高级管理人员执行职务违反法律、行政法规或者公司章程的规定，给公司造成损失的，应当承担赔偿责任。

2. 对第三人的赔偿责任

《公司法》第191条（新公司法新增）：

董事、高级管理人员执行职务，给他人造成损害的，公司应当承担赔偿责任；董事、高级管理人员存在故意或者重大过失的，也应当承担赔偿责任。

▲ 实务重难点：第191条突破了传统公司法中董事不对第三人直接承担责任的原则，是新公司法的重大突破。但该条的适用条件限于"故意或者重大过失"，一般过失不构成对第三人的直接赔偿责任。

一般员工职务侵权 vs 董高职务侵权对比：

比较维度 一般员工（《民法典》第1191条） 董事、高管（《公司法》第191条）
单位责任 单位承担侵权责任 公司承担赔偿责任
个人外部责任 无外部责任 有外部责任：存在故意或重大过失的，也应承担赔偿责任
内部追偿 单位可向有故意或重大过失的员工追偿 公司可向有故意或重大过失的董高追偿

4.5 影子董事、高管（第192条）

◆ 《公司法》第192条：

公司的控股股东、实际控制人指示董事、高级管理人员从事损害公司或者股东利益的行为的，与该董事、高级管理人员承担连带责任。

3. 股东代表诉讼

《公司法》第189条（法条原文）：

董事、高级管理人员有前条规定的情形的，有限责任公司的股东、股份有限公司连续一百八十日以上单独或者合计持有公司百分之一以上股份的股东，可以书面请求监事会向人民法院提起诉讼；监事有前条规定的情形的，前述股东可以书面请求董事会向人民法院提起诉讼。

监事会或者董事会收到前款规定的股东书面请求后拒绝提起诉讼，或者自收到请求之日起三十日内未提起诉讼，或者情况紧急、不立即提起诉讼将会使公司利益受到难以弥补的损害的，前款规定的股东有权为公司利益以自己的名义直接向人民法院提起诉讼。

他人侵犯公司合法权益，给公司造成损失的，本条第一款规定的股东可以依照前两款的规定向人民法院提起诉讼。

公司全资子公司的董事、监事、高级管理人员有前条规定情形，或者他人侵犯公司全资子公司合法权益造成损失的，有限责任公司的股东、股份有限公司连续一百八十日以上单独或者合计持有公司百分之一以上股份的股东，可以依照前三款规定书面请求全资子公司的监事会、董事会向人民法院提起诉讼或者以自己的名义直接向人民法院提起诉讼。

代表诉讼的要点：

要素 内容
起因 公司/全资子公司利益受损，而非股东直接利益受损
原告 有限公司：任意股东；股份公司：连续180日以上且单独或合计持股1%以上的股东；起诉时具有股东资格
被告 致损方：损害公司/全资子公司利益的董监高、其他人
第三人 公司/全资子公司
利益归属 公司/全资子公司
合理费用 股东的诉讼请求部分或全部得到法院支持的，公司应当承担股东因参加诉讼支付的合理费用

前置程序（交叉请求）：

  • 董事、高管损害公司利益 → 股东书面请求监事会提起诉讼
  • 监事、他人损害公司利益 → 股东书面请求董事会提起诉讼
  • 审计委员会替代：若公司不设立监事会而设立审计委员会，则董事、高管损害公司利益时，应当请求审计委员会，由审计委员会中无利害关系的成员代表公司参加诉讼

内部机构不起诉时，股东可以起诉的三种情形：

  1. 监事会或董事会收到股东书面请求后拒绝提起诉讼
  2. 监事会或董事会自收到股东书面请求之日起30日内未提起诉讼
  3. 情况紧急、不立即提起诉讼将会使公司利益受到难以弥补的损害

无须履行前置程序的情形（股东可以直接起诉）：

  1. 情况紧急、不立即提起诉讼将会使公司利益受到难以弥补的损害
  2. 公司有关机关不存在起诉可能性

反诉规则（以他人为被告的代表诉讼中）：

  • 应受理：被告以原告股东恶意起诉侵犯其合法权益为由提起反诉的
  • 不受理：被告以公司在案涉纠纷中应当承担侵权或者违约等责任为由对公司提出的反诉（公司系第三人，被告起诉公司的，不构成反诉）

调解规则：

  • 只有在调解协议经公司股东会、董事会决议通过后，人民法院才能出具调解书予以确认
  • 具体决议机关，由公司章程规定；公司章程没有规定的，以股东会为决议机关

关联交易损害公司利益时的代表诉讼：

  1. 公司的控股股东、实际控制人、董事、监事、高级管理人员利用其关联关系损害公司利益，公司没有提起诉讼的，符合代表诉讼规定条件的股东，可以按照代表诉讼的相关规定向人民法院提起诉讼
  2. 关联交易合同存在无效、可撤销或者对公司不发生效力的情形，公司没有起诉合同相对方的，符合条件的股东依法提起股东代表诉讼的，人民法院应予受理

5. 股东的直接诉讼

董事、高级管理人员违反法律、行政法规或者公司章程的规定，损害股东利益的，股东可以向人民法院提起诉讼。

【归纳总结】直接诉讼与代表诉讼对比：

比较维度 直接诉讼 代表诉讼
起因 股东利益受损 公司/全资子公司利益受损
原告 受损股东 有限公司：任意股东；股份公司：连续180日以上且持股1%以上
被告 违反法律、法规、章程，损害股东利益的董事、高管 损害公司/全资子公司利益的董监高、他人
前置程序 无 书面交叉请求，除非拒绝、30日、紧急、无可能
利益归属 股东 公司/全资子公司

4. 归入权

《公司法》第186条：

董事、监事、高级管理人员违反本法第一百八十一条至第一百八十四条规定所得的收入应当归公司所有。

归入权的适用范围：违反禁止行为（第181条）、自我交易（第182条）、谋取公司商业机会（第183条）、竞业限制（第184条）所得的收入均应归公司所有。

（五）◆ 关联交易规制（自我交易）

《公司法》第182条：

董事、监事、高级管理人员，直接或者间接与本公司订立合同或者进行交易，应当就与订立合同或者进行交易有关的事项向董事会或者股东会报告，并按照公司章程的规定经董事会或者股东会决议通过。

自我交易的范围（以下主体与公司订立合同或进行交易，均属自我交易）：

  1. 董事、监事、高级管理人员本人
  2. 董事、监事、高级管理人员的近亲属
  3. 董事、监事、高级管理人员或者其近亲属直接或者间接控制的企业
  4. 与董事、监事、高级管理人员有其他关联关系的关联人

关联交易的程序要求：

  1. 报告义务：应当就与订立合同或者进行交易有关的事项向董事会或者股东会报告
  2. 决议：按照公司章程的规定经董事会或者股东会决议通过
  3. 回避制度：关联董事不得参与表决，其表决权不计入表决权总数（第139条）
  4. 人数不足的处理：出席董事会会议的无关联关系董事人数不足3人的，应当将该事项提交股东会审议

▲ 实务重难点：新公司法将关联交易的规制范围扩展至"直接或者间接"与本公司进行交易，包括关联人通过其控制的其他企业与公司进行的交易，大幅扩大了关联交易的监管覆盖面。

（六）◆ 竞业禁止与商业机会篡夺

竞业禁止义务（第183条）

董事、监事、高级管理人员未向董事会或者股东会报告，并经董事会或者股东会决议通过，不得自营或者为他人经营与所任职公司同类的业务。

违反竞业禁止的法律后果：

  • 归入权：所得收入归公司所有（第186条）
  • 赔偿责任：给公司造成损失的，应当承担赔偿责任

商业机会篡夺（第184条）

董事、监事、高级管理人员未向董事会或者股东会报告，并经董事会或者股东会决议通过，不得利用职务便利为自己或者他人谋取属于公司的商业机会。

例外情形（董监高可以谋取公司商业机会的两种情形）：

  1. 向董事会或者股东会报告，并按照公司章程的规定经董事会或者股东会决议通过
  2. 根据法律、行政法规或者公司章程的规定，公司不能利用该商业机会

"属于公司的商业机会"的判断标准：

  • 公司是否已在就该商业机会进行谈判或投入资源
  • 该商业机会是否与公司现有业务密切相关
  • 公司是否有能力和资源利用该商业机会

四、案例分析

案例：董事违反忠实义务——竞业禁止与关联交易

【案情】

张某是某市知名连锁餐饮企业盛和楼餐饮管理有限公司的董事兼运营副总。2023年起，张某在未向公司董事会或股东会报告的情况下，以其配偶名义注册成立了聚味坊餐饮有限公司，经营与盛和楼同类型的中式正餐业务。张某利用在盛和楼的职务便利，将盛和楼积累的供应商资源和大客户渠道转介给聚味坊，并将盛和楼三家门店的区域经理调至聚味坊任职。

2024年底，盛和楼发现其华东区域营业收入同比下降35%，而聚味坊同期在相同商圈快速扩张。盛和楼审计后发现张某的行为，遂诉至法院。

【法律分析】

  1. 竞业禁止违反：张某以配偶名义经营同类餐饮业务，属于《公司法》第183条规定的"为他人经营与所任职公司同类的业务"，构成竞业禁止义务的违反

  2. 关联交易违反：张某未就其与聚味坊的关联关系向董事会或股东会报告，违反第182条的关联交易报告义务和决议程序

  3. 商业机会篡夺：张某将盛和楼的客户资源和供应商渠道转介给聚味坊，构成第184条规定的"利用职务便利谋取属于公司的商业机会"

  4. 法律责任：

    • 盛和楼可依据第186条行使归入权，要求张某将聚味坊的经营所得归入公司
    • 盛和楼可依据第188条要求张某赔偿公司因客户流失和营业收入下降所遭受的损失
    • 盛和楼股东可依据第189条提起股东代表诉讼

【实务启示】

▲ 董事、高管以配偶、近亲属名义经营同类业务，同样构成竞业禁止义务的违反。公司应在章程和高管聘用合同中明确竞业限制范围、违约金标准和归入权的行使方式。

案例：影子董事与职务侵权的责任承担

【案情】

张平是兴华餐饮有限公司的法定代表人兼董事长，洪河沙是兴华公司的实际控制人，但未担任任何公司职务。2025年初，兴华公司因食品安全问题面临多起消费者维权诉讼。

张平在日常管理中放任采购员采购低价不合格牛肉，造成顾客张某食物中毒住院治疗，产生医疗费及赔偿费用共计18万元。

兴华公司餐厅服务员小强在2025年7月的一次上餐过程中因低头查看手机，不慎将滚烫的水煮肉片洒在顾客李某身上，造成李某二级烫伤。

洪河沙得知公司面临巨额赔偿后，指示张平将兴华公司的资金和优质门店资产紧急转移至洪河沙控制的另一家公司，导致兴华公司资金链断裂，无法正常运营，也无法对张某和李某进行赔偿。

【法律分析】

  1. 张某的权利：张某有权向兴华公司主张赔偿，也有权向董事长张平主张赔偿。张平放任采购不合格食材，存在故意或重大过失，属于职务侵权。依据《公司法》第191条，张某可以同时向公司和张平主张赔偿。

  2. 李某的权利：李某有权向兴华公司主张赔偿，但无权直接向服务员小强主张。小强的行为属于执行工作任务中的职务侵权，依据《民法典》第1191条，由兴华公司承担侵权责任。因小强存在重大过失（看手机上餐），兴华公司赔偿后可向小强追偿。

  3. 兴华公司的权利：兴华公司有权主张实际控制人洪河沙与董事长张平承担连带赔偿责任。洪河沙虽未担任公司职务，但其指示张平转移公司资产，损害公司利益，属于"影子董事"行为。依据《公司法》第192条，洪河沙与张平应承担连带责任。

六、实务要点

  1. 新公司法的治理结构选择：公司应在章程中明确选择监事会模式或审计委员会模式，两种模式不得并存
  2. 忠实义务的合规要点：关联交易、竞业行为必须履行报告义务并取得董事会或股东会的批准，且关联方应当回避表决
  3. 股东代表诉讼的实务操作：注意前置程序的要求，书面请求应当明确诉讼请求和事实理由
  4. 第191条的实务影响：债权人等第三人获得了直接向董事、高管主张赔偿的请求权基础，但需证明"故意或者重大过失"
  5. 审计委员会的组成要求：上市公司审计委员会的独立董事应当占多数，且至少一名独立董事为会计专业人士
