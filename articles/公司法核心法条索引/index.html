二、注册资本与出资 ◆

新公司法重大变化区域：2024年新公司法对出资制度作出重大修改，确立5年实缴期限，新增股东失权、出资加速到期等制度。

条款号 核心内容 关联知识点
第46条 有限公司章程应当载明事项：公司名称和住所、经营范围、注册资本、股东姓名或名称、出资方式和金额、公司机构及其产生办法、法定代表人等 📋 公司法知识库/05-公司的设立
第47条◆ 5年实缴期限：全体股东认缴的出资额应自公司成立之日起五年内缴足。法律、行政法规及国务院另有规定的除外 📋 公司法知识库/05-公司的设立
第48条 股东可以用货币出资，也可以用实物、知识产权、土地使用权、股权、债权等可以用货币估价并可依法转让的非货币财产作价出资。不得以劳务、信用、商誉等出资 📋 公司法知识库/05-公司的设立
第49条 股东应按期足额缴纳出资，未按期缴纳的应承担违约责任 📋 公司法知识库/05-公司的设立
第50条◆ 出资瑕疵责任与发起人连带责任：设立时股东未按期足额缴纳出资或非货币出资显著低于认缴额的，设立时的其他股东在出资不足范围内承担连带责任 📋 公司法知识库/05-公司的设立
第52条◆ 股东失权制度：股东未按期出资，经催缴（宽限期≥60日）仍未缴纳的，董事会决议发出失权通知，自通知发出之日起丧失未缴纳出资的股权 📋 公司法知识库/05-公司的设立
第53条 公司成立后，股东不得抽逃出资。抽逃出资的，负有责任的董监高应承担连带赔偿责任 📋 公司法知识库/05-公司的设立
第54条◆ 出资加速到期：公司不能清偿到期债务的，公司或已到期债权的债权人有权要求已认缴出资但未届出资期限的股东提前缴纳出资 📋 公司法知识库/05-公司的设立
第88条◆ 股权转让与出资责任：未届期股权转让——受让人承担出资义务，转让人承担补充责任；瑕疵股权转让——转让人与受让人连带责任 📋 公司法知识库/实务-股权转让与出资责任

三、股东资格与股东权利

条款号 核心内容 关联知识点
第20条 股东不得滥用股东权利损害公司或其他股东利益；不得滥用公司法人独立地位和股东有限责任损害债权人利益 📋 公司法知识库/06-股东资格与股东权利
第42条 有限公司由一个以上五十个以下股东出资设立 📋 公司法知识库/11-有限责任公司
第55条 有限公司应当向股东签发出资证明书 📋 公司法知识库/06-股东资格与股东权利
第56条 有限公司应当置备股东名册，记载股东姓名或名称、住所、出资额等 📋 公司法知识库/06-股东资格与股东权利
第57条◆ 知情权：股东有权查阅、复制公司章程、股东会会议记录、董事会会议决议、监事会会议决议和财务会计报告。股东可要求查阅公司会计账簿、会计凭证 📋 公司法知识库/06-股东资格与股东权利
第84条◆ 股权转让（有限公司）：股东之间可自由转让；向股东以外的人转让，应将有关事项书面通知其他股东，其他股东在同等条件下有优先购买权（新法删除"过半数同意"要求） 📋 公司法知识库/11-有限责任公司
第85条 人民法院强制执行股权时，应通知公司及全体股东，其他股东自通知之日起20日内不行使优先购买权视为放弃 📋 公司法知识库/11-有限责任公司
第86条 股权转让后，受让人自记载于股东名册时起可以向公司主张行使股东权利 📋 公司法知识库/11-有限责任公司
第89条◆ 异议股东回购请求权：（1）连续5年不分配利润且连续5年盈利；（2）合并、分立、转让主要财产；（3）章程规定的营业期限届满，股东会决议修改章程使公司存续。控股股东滥用权利损害公司或其他股东利益的，其他股东也有回购请求权 📋 公司法知识库/11-有限责任公司
第90条 自然人股东死亡后，其合法继承人可继承股东资格（章程另有规定除外） 📋 公司法知识库/11-有限责任公司

四、公司治理结构

条款号 核心内容 关联知识点
第15条 转投资限制与对外担保的决议程序 📋 公司法知识库/04-公司的能力
第59条◆ 股东会职权：选举和更换董事监事、审议批准董事会和监事会报告、审议批准利润分配和弥补亏损方案、增减注册资本、发行公司债券、合并分立解散清算变更公司形式、修改章程等。新法删除了"决定经营方针和投资计划"和"审批年度财务预决算方案" 📋 公司法知识库/11-有限责任公司
第63条 股东会会议由董事会召集，董事长主持 📋 公司法知识库/11-有限责任公司

第66条 特别决议（修改章程、增减注册资本、合并分立解散、变更公司形式）须经代表三分之二以上表决权的股东通过 📋 公司法知识库/11-有限责任公司
第67条◆ 董事会职权：召集股东会会议、执行股东会决议、决定经营计划和投资方案、制订利润分配方案、制订增减注册资本方案、制订合并分立解散方案、决定内部管理机构设置、聘任或解聘经理、制定基本管理制度等 📋 公司法知识库/11-有限责任公司
第68条 有限公司董事会成员为三人以上。职工人数三百人以上的公司，董事会成员中应有公司职工代表 📋 公司法知识库/11-有限责任公司
第69条▲ 审计委员会：有限公司可按章程规定在董事会中设置审计委员会行使监事会职权。设置审计委员会的，可以不设监事会或监事 📋 公司法知识库/07-董监高制度
第70条 董事任期由章程规定，每届任期不得超过三年，可连选连任 📋 公司法知识库/07-董监高制度
第74条 有限公司可设经理，由董事会决定聘任或解聘 📋 公司法知识库/07-董监高制度
第78条◆ 监事会职权：检查公司财务、监督董事高管执行职务、要求董事高管纠正损害公司利益的行为、提议召开临时股东会、向股东会提出提案、对董事高管提起诉讼等 📋 公司法知识库/07-董监高制度
第83条▲ 简化治理：规模较小或股东人数较少的有限公司，可不设董事会，设一名董事；不设监事会，设一至二名监事。经全体股东一致同意，也可不设监事 📋 公司法知识库/11-有限责任公司

五、董事、高级管理人员义务 ◆

新公司法重点强化区域：忠实义务与勤勉义务的细化、关联交易规制、股东代表诉讼、对第三人责任均为新公司法重大修改或强化内容。

条款号 核心内容 关联知识点
第21条 公司股东不得滥用股东权利损害公司或其他股东利益；不得滥用公司法人独立地位和股东有限责任损害公司债权人利益 📋 公司法知识库/02-公司法基础理论
第23条◆ 法人人格否认：第1款纵向否认——股东滥用法人独立地位和有限责任逃避债务，严重损害债权人利益的，对公司债务承担连带责任；第2款横向否认——股东利用其控制的两个以上公司实施前述行为的，各公司对任一公司债务承担连带责任；第3款一人公司举证责任倒置 📋 公司法知识库/02-公司法基础理论
第180条◆ 忠实义务与勤勉义务：董事、监事、高级管理人员对公司负有忠实义务，应避免自身利益与公司利益冲突，不得利用职权牟取不正当利益；负有勤勉义务，执行职务应为公司最大利益尽到管理者通常应有的合理注意。控股股东、实际控制人不担任公司董事但实际执行公司事务的，适用忠实义务和勤勉义务的规定（事实董事） 📋 公司法知识库/07-董监高制度
第181条◆ 禁止行为：不得侵占公司财产、挪用公司资金、将公司资金以其个人名义存储、利用职权收受贿赂或其他非法收入、擅自披露公司秘密、违反忠实义务的其他行为 📋 公司法知识库/07-董监高制度
第182条◆ 关联交易：董事、监事、高级管理人员直接或间接与公司订立合同或进行交易，应向董事会或股东会报告并经决议通过。涉及的董事不得行使表决权 📋 公司法知识库/07-董监高制度
第183条 竞业禁止：董事、高管未向董事会或股东会报告并经决议通过，不得自营或为他人经营与所任职公司同类的业务 📋 公司法知识库/07-董监高制度
第184条 商业机会：董事、高管不得利用职务便利谋取属于公司的商业机会（公司不能利用的除外） 📋 公司法知识库/07-董监高制度
第186条◆ 归入权：董事、高管违反第181-184条规定的，所得收入归公司所有 📋 公司法知识库/07-董监高制度
第188条◆ 对公司的赔偿责任：董事、高管执行职务违反法律、行政法规或公司章程，给公司造成损失的，应当承担赔偿责任 📋 公司法知识库/07-董监高制度
第189条◆ 股东代表诉讼：董事、高管损害公司利益的，有限公司股东、股份公司连续180日以上单独或合计持有公司1%以上股份的股东，可书面请求监事会（或董事会）向法院起诉；情况紧急的，股东可直接起诉 📋 公司法知识库/07-董监高制度
第191条 对第三人的赔偿责任：董事、高管执行职务，因故意或重大过失给他人造成损害的，应与公司承担连带责任 📋 公司法知识库/07-董监高制度
第192条 影子董事责任：控股股东、实际控制人指示董事、高管从事损害公司或股东利益的行为的，与该董事、高管承担连带责任 📋 公司法知识库/07-董监高制度

六、公司财务会计

条款号 核心内容 关联知识点
第209条 公司应在每一会计年度终了时编制财务会计报告，并依法经会计师事务所审计 📋 公司法知识库/08-公司财务会计
第210条◆ 利润分配：公司弥补亏损和提取公积金后所余税后利润，有限公司按实缴出资比例分配（章程另有规定除外）；股份公司按持股比例分配（章程另有规定除外） 📋 公司法知识库/08-公司财务会计
第211条 股东会决议违反法律、行政法规分配利润的，股东应将违反规定分配的利润退还公司 📋 公司法知识库/08-公司财务会计
第213条▲ 法定公积金：公司税后利润弥补亏损后提取10%列入法定公积金，累计额为注册资本50%以上时可不再提取。法定公积金不足以弥补以前年度亏损的，应先用当年利润弥补亏损 📋 公司法知识库/08-公司财务会计
第214条 公司经股东会决议可从税后利润中提取任意公积金 📋 公司法知识库/08-公司财务会计

七、公司变更 ▲

实务高频：合并、分立、减资、增资涉及债权人保护程序，实务中常引发纠纷。

条款号 核心内容 关联知识点
第218条▲ 公司合并：合并可采取吸收合并或新设合并。合并各方应签订合并协议，编制资产负债表及财产清单 📋 公司法知识库/09-公司重大变更
第219条▲ 公司合并，应自决议之日起10日内通知债权人，并于30日内在报纸上或国家企业信用信息公示系统公告。债权人自接到通知之日起30日内，未接到通知的自公告之日起45日内，可要求公司清偿债务或提供担保 📋 公司法知识库/09-公司重大变更
第220条 合并各方的债权、债务由合并后存续或新设的公司承继 📋 公司法知识库/09-公司重大变更
第222条▲ 公司分立：公司分立应编制资产负债表及财产清单。自决议之日起10日内通知债权人，并于30日内公告 📋 公司法知识库/09-公司重大变更
第223条 公司分立前的债务由分立后的公司承担连带责任（分立前与债权人达成书面协议另有约定的除外） 📋 公司法知识库/09-公司重大变更
第224条▲ 减资：公司减少注册资本，应编制资产负债表及财产清单。自决议之日起10日内通知债权人，并于30日内公告。债权人有权要求公司清偿债务或提供担保 📋 公司法知识库/09-公司重大变更
第225条▲ 简易减资：公司以弥补亏损为目的减少注册资本的，不需通知债权人，但应公告。公司减资后的注册资本不得低于法定最低限额 📋 公司法知识库/09-公司重大变更
第227条▲ 增资与优先认购权：有限公司增加注册资本时，股东有权优先按实缴出资比例认缴出资（章程另有规定除外） 📋 公司法知识库/09-公司重大变更

八、公司解散与清算

条款号 核心内容 关联知识点
第229条 解散事由：（1）章程规定的营业期限届满或章程规定的其他解散事由出现；（2）股东会决议解散；（3）因公司合并或分立需要解散；（4）依法被吊销营业执照、责令关闭或被撤销；（5）人民法院依法予以解散 📋 公司法知识库/10-公司解散与清算
第230条 出现第229条第1项情形的，可通过修改章程而存续 📋 公司法知识库/10-公司解散与清算
第231条◆ 司法解散：公司经营管理发生严重困难，继续存续会使股东利益受到重大损失，通过其他途径不能解决的，持有公司10%以上表决权的股东可请求人民法院解散公司 📋 公司法知识库/10-公司解散与清算
第232条◆ 清算义务人：公司因第229条第1、2、4、5项规定而解散的，应在解散事由出现之日起15日内成立清算组进行清算。董事为公司清算义务人 📋 公司法知识库/10-公司解散与清算
第233条 清算组由董事组成（章程另有规定或股东会决议另选他人除外） 📋 公司法知识库/10-公司解散与清算
第235条 清算组应自成立之日起10日内通知债权人，并于60日内在报纸上或国家企业信用信息公示系统公告 📋 公司法知识库/10-公司解散与清算
第240条▲ 简易注销：公司在存续期间未产生债务，或已清偿全部债务的，经全体股东承诺，可通过简易程序注销公司登记。全体股东对上述承诺承担连带责任 📋 公司法知识库/10-公司解散与清算
第241条 强制注销：公司被吊销营业执照、责令关闭或被撤销的，满三年未向市场监督管理部门申请注销的，市场监督管理部门可依法注销 📋 公司法知识库/10-公司解散与清算

第135条 上市公司在一年内购买、出售重大资产或担保金额超过公司资产总额30%的，应由股东大会作出决议，并经出席会议的股东所持表决权的三分之二以上通过 📋 公司法知识库/12-股份有限公司

第142条 面额股与无面额股：公司发行的股票可以为面额股，也可以为无面额股。发行无面额股的，应将发行股份所得股款的二分之一以上计入注册资本 📋 公司法知识库/12-股份有限公司
第158条 股东转让股份，应当在依法设立的证券交易场所进行，或者按照国务院规定的其他方式进行 📋 公司法知识库/12-股份有限公司
第159条 发起人锁定期：发起人持有的本公司股份，自公司成立之日起一年内不得转让 📋 公司法知识库/12-股份有限公司
第160条 董监高持股转让限制：任职期间每年转让不得超过其所持股份总数的25%；上市交易之日起1年内不得转让；离职后半年内不得转让 📋 公司法知识库/12-股份有限公司
第162条 公司收购本公司股份：法定情形——减少注册资本（10日内注销）、与其他公司合并（6个月内转让或注销）、员工持股计划或股权激励（合计不超过已发行股份10%，3年内转让或注销）等 📋 公司法知识库/12-股份有限公司

下表列出新公司法相对2018年修正版公司法的重大修改条款。

主题 新公司法条款 2018年公司法原条款 主要变化
出资期限 第47条：5年实缴期限 原第26条：无期限限制（2013年全面认缴制） 确立5年认缴期限，纠正全面认缴制弊端
出资加速到期 第54条：不能清偿到期债务即可加速到期 原无明确规定（《九民纪要》第6条为标准） 法律层面确立加速到期，降低债权人举证门槛

股权转让 第84条：通知+优先购买权 原第71条：过半数同意规则 删除"过半数同意"前置程序，简化转让规则

关联交易 第182条：事前报告+决议程序 原第148条、第21条：原则性禁止 程序化规制，明确披露和表决机制
股东代表诉讼 第189条：完善前置程序 原第151条 条件更明确，增加"情况紧急"直接起诉规定
对第三人责任 第190-191条 原无明确规定 新增董事对第三人责任、实际控制人连带责任
横向人格否认 第23条第2款 原第20条第3款（仅纵向否认） 新增横向否认，打击关联公司逃债
简易减资 第225条 原无此制度 新增减资程序简化，专门用于弥补亏损
简易注销 第240条 原无此制度 新增简易注销，简化无债务公司退出程序
