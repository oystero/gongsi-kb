公司的分类

总论 7560字 19 分钟阅读

实务指引：公司类型的选择直接影响股东权利义务、税负和融资能力，是公司设立时的首要决策

二、按股东责任分类

（一）无限公司

定义：无限公司是指全体股东对公司债务承担无限连带责任的公司。

特征：

  1. 无限责任：股东对公司债务承担无限清偿责任
  2. 连带责任：股东之间对公司债务承担连带责任
  3. 人合性强：以股东之间的信任关系为基础
  4. 设立简便：设立程序简单，无需最低资本

我国法律的态度：我国《公司法》不承认无限公司，仅规定有限责任公司和股份有限公司两种形式。

（二）两合公司

定义：两合公司是指由无限责任股东和有限责任股东共同组成的公司。

特征：

  1. 双重责任：无限责任股东承担无限连带责任，有限责任股东以出资额为限承担责任
  2. 人合兼资合：兼具无限公司的人合性和有限公司的资合性
  3. 管理权限制：有限责任股东一般不参与公司经营管理
  4. 利润分配灵活：可以约定不同于出资比例的分配方式

我国法律的态度：我国《公司法》不承认两合公司，但有限合伙企业（《合伙企业法》）具有类似特征。

（三）有限责任公司

◆ 有限责任公司的特征：

《公司法》第42条规定：“有限责任公司由一个以上五十个以下股东出资设立。”

特征 具体内容 法律依据
股东人数 1人以上50人以下 第42条
责任形式 股东以认缴出资额为限对公司承担责任 第3条
资本形式 股东出资，不分为等额股份 第47条
股权转让 对外转让需其他股东过半数同意，其他股东有优先购买权 第84条
组织机构 可设董事会、监事会，也可不设 第69条、第83条
信息公开 信息公开程度较低 -

有限责任公司的优点：

  1. 设立门槛相对较低
  2. 股东人数限制，人合性强
  3. 股权转让限制，公司稳定性高
  4. 组织机构灵活，治理成本低

有限责任公司的缺点：

  1. 筹资能力有限
  2. 股权转让受限
  3. 不能公开发行股票

（四）股份有限公司

◆ 股份有限公司的特征：

《公司法》第92条规定：“设立股份有限公司，应当有二人以上二百人以下为发起人，其中应当有半数以上的发起人在中国境内有住所。”

特征 具体内容 法律依据
发起人人数 2人以上200人以下 第92条
责任形式 股东以认购股份为限对公司承担责任 第3条
资本形式 全部资本分为等额股份 第142条
股权转让 股份可以依法自由转让 第157条
组织机构 必须设立股东大会、董事会、监事会 第120条
信息公开 上市公司信息公开程度高 第152条

股份有限公司的优点：

  1. 筹资能力强
  2. 股份转让自由
  3. 公司规模可以较大
  4. 所有权与经营权分离

股份有限公司的缺点：

  1. 设立门槛较高
  2. 治理结构复杂
  3. 信息公开成本高
  4. 股东流动性大，稳定性较差

（五）有限责任公司与股份有限公司的对比

▲ 重点对比：

对比项 有限责任公司 股份有限公司
股东人数 1-50人 2-200人（发起人）
资本形式 出资额，不等分 等额股份
设立方式 仅发起设立 发起设立或募集设立
股权转让 有限制，需其他股东同意 自由转让（发起人除外）
组织机构 灵活，可简化 必须三会齐全
公开程度 较低 较高（上市公司最高）
适用规模 中小型企业 大型企业
融资能力 较弱 较强
设立程序 简便 复杂
治理成本 较低 较高

◆ 有限公司与股份公司的四大区别：

区别 有限责任公司 股份有限公司
1. 股本是否拆分 不对股本进行等额拆分，股东通过章程约定持有一定比例的股权 将股本作等额拆分，每一份额为一张股票，股东按照持有的股份数量行使表决权
2. 股权（股份）流动性 股权未作等额拆分，流动性较弱 因股本的等额拆分，股份流动性较强
3. 公司规模大小 股权流动性较弱，资金募集能力相对较差，规模相对较小 股份具有较强的流动性，更容易募集资金、做大做强，规模相对较大
4. 运营特点与监管态度 追求灵活性，具有更多的章程自治空间 追求规范性，公司法在很多方面对其作出了硬性规定，监管态度较为严格

三、按信用基础分类

（一）人合公司

定义：以股东个人信用为基础的公司。

特征：

  1. 信用基础：公司的信用依赖于股东个人的信用
  2. 股东关系：股东之间有较强的信任关系
  3. 责任形式：通常承担无限责任
  4. 典型形式：无限公司

（二）资合公司

定义：以公司资本信用为基础的公司。

特征：

  1. 信用基础：公司的信用依赖于公司资本的多少
  2. 股东关系：股东之间无需特别信任关系
  3. 责任形式：有限责任
  4. 典型形式：股份有限公司

（三）人合兼资合公司

定义：兼具人合性和资合性特征的公司。

特征：

  1. 信用基础：兼具股东个人信用和公司资本信用
  2. 股东关系：有一定信任关系，但不如人合公司紧密
  3. 责任形式：有限责任，但股权转让有限制
  4. 典型形式：有限责任公司

我国公司的分类：

公司类型 信用基础 人合性 资合性
有限责任公司 人合兼资合 较强 较强
股份有限公司（非上市） 资合为主 较弱 强
股份有限公司（上市） 资合 无 很强

◆ 人合性与资合性的详细对比：

公司类型 信用基础 人合性体现 资合性体现
有限公司 人合为主，兼有资合性 ①股东人数较少，股东之间往往具有亲密关系；②对外转让股权，原股东有优先购买权；③增加注册资本时，原股东有优先认缴权 —
非上市的股份公司 资合为主，兼有人合性 — ①股东人数较多，股东之间一般不具有亲密关系；②对外转让股份时，原股东没有优先购买权；③增加注册资本时，原股东没有优先认缴权

归纳总结表：

分类 说明
人合公司 我国没有绝对意义上的人合公司
人合兼资合公司 有限公司：人合为主兼有资合性；非上市的股份公司：资合为主兼有人合性
资合公司 股份公司中的上市公司

四、按组织关系分类

（一）母公司与子公司

◆ 母子公司的法律关系：

《公司法》第14条第2款规定：“公司可以设立子公司，子公司具有法人资格，依法独立承担民事责任。”

母子公司的特征：

特征 具体内容
控制关系 母公司持有子公司50%以上股权或能够实际控制
法人资格 子公司具有独立法人资格
责任承担 子公司独立承担民事责任
人格独立 子公司与母公司的人格相互独立

母公司对子公司的控制方式：

  1. 股权控制：持有子公司多数股权
  2. 协议控制：通过协议约定控制子公司
  3. 人事控制：通过派遣董事、高管控制子公司
  4. 财务控制：控制子公司的财务和资金

▲ 母子公司的法律风险：

  1. 人格否认风险：母公司过度控制子公司，可能导致人格否认
  2. 关联交易风险：母子公司之间的交易可能被认定为关联交易
  3. 债务传染风险：人格混同可能导致子公司对母公司债务负责

（二）总公司与分公司

◆ 总分公司的法律关系：

《公司法》第14条第1款规定：“公司可以设立分公司。设立分公司，应当向公司登记机关申请登记，领取营业执照。分公司不具有法人资格，其民事责任由公司承担。”

总分公司的特征：

特征 具体内容 法律依据
法人资格 分公司不具有法人资格 第14条
责任承担 分公司的民事责任由总公司承担 第14条
营业执照 分公司领取营业执照 第14条
诉讼主体 分公司可以作为诉讼当事人 《民事诉讼法》第51条

（三）母公司与子公司 vs 总公司与分公司

▲ 重点对比：

对比项 母公司与子公司 总公司与分公司
法人资格 子公司具有法人资格 分公司不具有法人资格
责任承担 子公司独立承担责任 分公司由总公司承担责任
设立依据 公司章程、投资协议 总公司决定设立
经营自主权 子公司有较大自主权 分公司自主权较小
财务独立 子公司财务独立 分公司财务非独立
诉讼地位 独立的诉讼当事人 可以作为诉讼当事人

五、按注册地分类

（一）本国公司

定义：依照中国法律在中国境内设立的公司。

特征：

  1. 适用中国公司法
  2. 在中国境内注册登记
  3. 具有中国法人资格

（二）外国公司

《公司法》第242条规定：“本法所称外国公司是指依照外国法律在中国境外设立的公司。”

外国公司的特征：

  1. 依照外国法律设立
  2. 在中国境外设立
  3. 在中国境内从事经营活动需要设立分支机构

▲ 外国公司分支机构的特殊规定：

  1. 必须在中国境内指定负责该分支机构的代表人或代理人
  2. 向该分支机构拨付与其所从事的经营活动相适应的资金
  3. 分支机构的民事责任由外国公司承担

六、按是否上市分类

（一）上市公司

◆ 上市公司的特征：

《公司法》第152条规定：“本法所称上市公司，是指其股票在证券交易所上市交易的股份有限公司。”

特征 具体内容 法律依据
公司形式 必须是股份有限公司 第152条
股票交易 股票在证券交易所上市交易 第152条
信息公开 必须定期披露财务报告和重大事项 第152条
治理要求 必须设立独立董事、董事会秘书 第136条、第137条
监管要求 受证监会和证券交易所监管 -

上市公司的特殊规定：

  1. 独立董事制度：上市公司设独立董事，具体办法由国务院规定（第136条）
  2. 董事会秘书：上市公司设董事会秘书，负责公司股东大会和董事会会议的筹备、文件保管以及公司股东资料的管理，办理信息披露事务等（第137条）
  3. 关联交易：上市公司的关联交易应当严格遵守信息披露和公平交易原则

（二）非上市公司

非上市公司的特征：

  1. 股票不在证券交易所交易
  2. 信息公开要求较低
  3. 治理结构相对简单
  4. 包括有限责任公司和非上市股份有限公司

七、新公司法下的特殊类型

（一）国有独资公司

◆ 国有独资公司的特殊规定：

《公司法》第168条规定：“国有独资公司的设立和组织机构，适用本节规定；本节没有规定的，适用本章第一节、第二节的规定。”

国有独资公司的特征：

特征 具体内容 法律依据
股东 国家单独出资 第168条
出资人机构 国务院或者地方人民政府授权的国有资产监督管理机构 第169条
公司形式 有限责任公司 第168条
治理结构 不设股东会，由出资人机构行使股东会职权 第172条
党组织 公司党组织发挥领导作用 第170条
董事会 应当有过半数的外部董事 第173条

▲ 国有独资公司的特殊治理：

  1. 不设股东会：由国有资产监督管理机构行使股东会职权
  2. 党组织领导：党组织研究讨论是董事会、经理层决策重大问题的前置程序
  3. 外部董事：董事会成员中应当有过半数的外部董事
  4. 审计委员会：国有独资公司在董事会中设置由董事组成的审计委员会行使监事会职权的，不设监事会或者监事

（二）一人有限责任公司

◆ 一人有限责任公司的特殊规定：

《公司法》第23条第3款规定：“只有一个股东的有限责任公司的股东不能证明公司财产独立于股东自己的财产的，应当对公司债务承担连带责任。”

一人有限责任公司的特征：

特征 具体内容 法律依据
股东人数 1个自然人或1个法人 第42条
公司形式 有限责任公司 第42条
举证责任 股东需证明公司财产独立 第23条
再投资限制 一个自然人只能投资设立一个一人有限责任公司 -

▲ 一人有限责任公司的风险防范：

  1. 建立规范的财务制度：保持公司财务与股东个人财务严格分离
  2. 年度审计：每一会计年度终了时编制财务会计报告，并经会计师事务所审计
  3. 独立账户：公司账户与股东个人账户分开
  4. 交易记录：公司每一笔交易都应有清晰的记录

（三）国有资本控股公司

定义：国有资本占控股地位的公司。

特征：

  1. 资本结构：国有资本占控股地位
  2. 公司形式：可以是有限责任公司或股份有限公司
  3. 治理结构：适用公司法一般规定，同时适用国家出资公司的特别规定
  4. 党组织：公司党组织发挥领导作用

九、实务要点：选择公司类型的考量因素

（一）选择有限责任公司的情形

◆ 适合选择有限责任公司的情形：

  1. 中小型企业：股东人数较少，规模较小
  2. 人合性强：股东之间有较强的信任关系
  3. 控制需求：希望限制股权对外转让，保持公司稳定
  4. 灵活治理：希望简化治理结构，降低管理成本
  5. 家族企业：家族成员共同经营

（二）选择股份有限公司的情形

◆ 适合选择股份有限公司的情形：

  1. 大型企业：规模较大，需要大量资金
  2. 公开融资：计划公开发行股票或上市
  3. 股权流动性：希望股权能够自由转让
  4. 规范化治理：希望建立规范的公司治理结构
  5. 股权激励：计划实施员工持股计划

（三）选择一人有限责任公司的情形

◆ 适合选择一人有限责任公司的情形：

  1. 个人创业：一个人独立创业
  2. 全资子公司：母公司设立全资子公司
  3. 风险隔离：希望通过公司形式隔离个人风险
  4. 特定项目：为特定项目设立项目公司

▲ 一人公司的风险提示：

  • 股东需承担证明公司财产独立的举证责任
  • 建立规范的财务制度，保持财务独立
  • 进行年度审计，保留审计报告作为证据

（四）选择国有独资公司的情形

◆ 适合选择国有独资公司的情形：

  1. 国有资产经营：国有资本的经营和管理
  2. 公共服务：提供公共产品和服务
  3. 战略产业：关系国家安全和国民经济命脉的产业
  4. 政府投资：政府直接投资的企业

十、案例分析与实务要点

案例一：母子公司关系与人格否认

案情：锦绣集团是一家从事房地产开发的集团公司，持有锦绣置业80%的股权。锦绣集团因资金链紧张，指示锦绣置业将名下三处优质商业地产以明显低于市场评估价的价格转让给锦绣集团的关联公司。锦绣置业的建筑供应商远达建材对锦绣置业享有650万元货款债权，因锦绣置业资产被掏空，债权无法实现。

分析结论：

  1. 母公司对子公司的控制应保持在合理范围内，不得利用控制地位损害子公司及其债权人的利益
  2. 母公司将子公司资产以明显不合理低价转移，属于滥用法人独立地位的典型表现（《公司法》第23条第1款）
  3. 依据法人人格否认制度，锦绣集团应对锦绣置业的650万元债务承担连带清偿责任

参考案例：最高法指导案例15号——徐工集团诉川交工贸等案（（2011）苏商终字第0107号），确认了关联公司人格混同的认定标准。

案例二：总公司与分公司的责任承担

案情：宏远餐饮管理有限公司总部位于某省会城市，在该市设立了多家分公司。其中第一分公司在经营过程中拖欠食材供应商绿源农产品公司货款52万元。绿源公司起诉要求宏远公司总部和第一分公司共同承担还款责任。

分析结论：

  1. 分公司不具有法人资格，其民事责任由总公司承担（《公司法》第14条第1款）
  2. 分公司可以作为诉讼当事人参加诉讼，但责任最终由总公司承担
  3. 实务提示：债权人在与分公司交易时，应关注总公司的资信状况；分公司不具有独立法人地位，不能独立承担民事责任

案例三：一人公司财产混同

案情：王某独资设立了鑫达贸易有限公司（一人有限责任公司），从事服装批发业务。鑫达公司向供货商赵某采购了价值85万元的服装，但仅支付了30万元。赵某诉至法院，同时要求王某对公司债务承担连带责任。诉讼中，王某未能提交鑫达公司的年度审计报告；经查，公司经营资金和个人消费支出混同使用同一银行账户，无法区分公司财产与个人财产的界限。

分析结论：

  1. 一人有限责任公司的股东承担证明公司财产独立于个人财产的举证责任（举证责任倒置），法律依据为《公司法》第23条第3款
  2. 年度审计报告是证明财产独立的关键证据，未提供审计报告将面临举证不能的不利后果
  3. 公司账户与个人账户混同使用是认定财产混同的核心事实
  4. 实务建议：一人公司股东应建立规范的财务制度，每年度编制财务会计报告并经会计师事务所审计，保持公司账户与个人账户严格分离

参考案例：最高人民法院在（2019）最高法民终1093号、（2018）最高法民终1485号等裁判中确认：一人公司股东未能提交连续年度审计报告的，视为未能完成举证责任，应对公司债务承担连带责任。
