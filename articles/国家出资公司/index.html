二、核心制度详解

（一）国家出资公司的概念与范围

◆ 新公司法设专章（第七章）规定"国家出资公司组织机构的特别规定"，这是新公司法的重大立法创新。《公司法》第168条规定：国家出资公司，是指国家出资的国有独资公司、国有资本控股公司，包括国家出资的有限责任公司、股份有限公司。

▲ 实务中需注意以下两点：

  1. 国家出资公司仅限于国家直接出资的公司，而不包括国家出资公司再投资设立的公司。
  2. 国有资本参股公司不属于国家出资公司。

中石油集团与中石油股份公司的区别

中国石油天然气集团有限公司（简称中石油集团）由国务院国资委100%持股，系国有独资公司，属于国家出资公司。中国石油天然气股份有限公司（简称中石油股份公司，SH.601857）由中石油集团持股82.46%，系国家出资公司再投资设立的公司，不属于国家出资公司。

国有独资公司的概念

◆ 国有独资公司，是指国家单独出资、由国务院或者地方人民政府授权本级人民政府国有资产监督管理机构履行出资人职责的公司。国有独资公司是国家出资公司的特殊形态，适用第七章的特别规定。

履行出资人职责的机构

  1. 国家出资公司，由国务院或者地方人民政府分别代表国家依法履行出资人职责，享有出资人权益。《公司法》第169条
  2. 国务院或者地方人民政府可以授权国有资产监督管理机构或者其他部门、机构代表本级人民政府对国家出资公司履行出资人职责。代表本级人民政府履行出资人职责的机构、部门，统称为履行出资人职责的机构。

（二）◆ 国家出资公司的特殊治理结构

1. 不设股东会，由履行出资人职责的机构行使股东会职权

◆ 《公司法》第172条规定：国有独资公司不设股东会，由履行出资人职责的机构行使股东会职权。履行出资人职责的机构可以授权公司董事会行使股东会的部分职权，但公司章程的制定和修改，公司的合并、分立、解散、申请破产，增加或者减少注册资本，分配利润，应当由履行出资人职责的机构 决定。

▲ 须由履行出资人职责的机构决定的事项：

根据 《公司法》第66条 第3款，有限责任公司股东会的特别决议事项（经代表三分之二以上表决权的股东通过）共6项：①修改公司章程；②增加或者减少注册资本；③公司合并；④公司分立；⑤公司解散；⑥变更公司形式。

此外，《公司法》第15条规定"为他人提供担保"由公司章程规定由董事会或股东会决议——此即第66条所附"7个特别决议事项"中"⑦为他人提供担保"的来源。

国有独资公司不设股东会，减去"变更公司形式"（没有股东会即无此决议需求），加上"申请破产"和"分配利润"（《公司法》第172条国有资产监管的特殊性要求），形成"7-1+2"规则。此外，"为他人提供担保"虽非法定的三分之二特别决议事项（第15条授权章程规定），但国有独资公司章程由出资人机构制定（第171条），实务中该事项也属于出资人机构的决策范围。共8项事项须由出资人机构决定：

"7-1+2"规则（第66条调整 + 第172条新增）：

  1. 公司章程的制定和修改
  2. 公司的合并、分立、解散
  3. 申请破产 ← 第172条新增
  4. 增加或者减少注册资本
  5. 分配利润 ← 第172条新增

章程规定的特别事项（第15条 + 第171条）： 6. 为他人提供担保 ← 第15条授权章程规定；国有独资公司章程由出资人机构制定，故该事项实质上也由出资人机构决定

2. 董事会：外部董事应过半数，应有职工代表

◆ 《公司法》第173条规定：国有独资公司应当设立董事会。董事会成员中，应当过半数为外部董事，并应当有职工代表。

董事会成员的产生方式：

  • 董事会成员由履行出资人职责的机构委派
  • 董事会成员中的职工代表由公司职工代表大会选举产生
  • 设董事长1人，可以设副董事长。董事长、副董事长由履行出资人职责的机构从董事会成员中指定

外部董事制度 是新公司法强化国有公司治理的重要举措：

  • 外部董事不在公司担任除董事以外的其他职务
  • 目的是增强董事会的独立性和决策科学性
  • 有效防止"内部人控制"问题

3. 经理与任职限制

◆ 《公司法》第174条规定：

  • 经理由董事会聘任或者解聘
  • 经履行出资人职责的机构同意，董事会成员可以兼任经理

◆ 《公司法》第175条规定：

  • 董事、高级管理人员，未经履行出资人职责的机构同意，不得在其他有限责任公司、股份有限公司或者其他经济组织兼职

4. 党组织的领导作用

◆ 《公司法》第170条规定：国家出资公司中中国共产党的组织，按照中国共产党章程的规定发挥 领导作用，研究讨论公司重大经营管理事项，支持公司的组织机构依法行使职权。

▲ 这是新公司法首次在公司法层面明确党组织在国家出资公司中的领导地位，将党的领导融入公司治理的法律框架之中。

（三）国有独资公司的特别规定

1. 章程制定

国有独资公司的章程由 履行出资人职责的机构 制定（《公司法》第171条）。这与一般公司的章程由股东共同制定存在根本区别，体现了国家作为唯一股东的意思自治。

▲ 实务要点：章程的制定和修改属于"7-1+2"事项之一（见上文第8项），必须由履行出资人职责的机构决定，不得授权董事会自行决定。

2. 审计委员会与监事会

◆ 《公司法》第176条规定：国有独资公司在董事会中设置由董事组成的审计委员会行使本法规定的监事会职权的，不设监事会或者监事。

▲ 实务中，国有独资公司可根据自身情况选择：

  • 设置审计委员会替代监事会
  • 继续保留监事会
  • 仅设一名监事

设立审计委员会并非强制性要求，属于公司自治范畴。

（四）关联交易与董事责任

1. 关联交易的规制

◆ 《公司法》第177条要求国家出资公司应当依法建立健全内部监督管理和风险控制制度，加强内部合规管理。

国家出资公司关联交易的规制主要通过以下途径实现：

  • 公司章程与合规管理制度：建立关联方识别、关联交易审批与回避机制
  • 《企业国有资产法》等配套法规：禁止国有资本控股公司无偿向关联方提供资金、商品、服务或其他资产，禁止以不公平价格与关联方交易
  • 信息披露义务：关联交易应当及时披露，接受监管

关联交易规制的核心目标是防止国有资本通过关联交易被不当输送给关联方，是防止国有资产流失的重要制度屏障。

2. 董事的责任与免责

◆ 《公司法》第125条规定：董事会决议违反法律、行政法规或者公司章程、股东会决议，给公司造成严重损失的，参与决议的董事对公司负赔偿责任；经证明在表决时曾表明异议并记载于会议记录的，该董事可以免除责任。

▲ 实务要点：在国家出资公司中，董事会决议涉及重大资产处置、关联交易等事项时，董事应特别注意：

  1. 投反对票的董事必须要求将异议意见完整记载于会议记录
  2. 会议记录是免责的唯一证据载体，口头异议不产生免责效力

（五）国有资产评估与转让

◆ 以下内容主要依据《企业国有资产法》《企业国有资产交易监督管理办法》（32号令）等配套法规，公司法本身未在第七章中直接规定评估与转让程序。

1. 评估程序

国有资产转让应当依法进行 资产评估。未经评估的，不得进行转让。评估应当委托具有相应资质的评估机构进行，评估结果应当报履行出资人职责的机构核准或者备案。

2. 转让程序

国有资产转让应当遵循以下程序要求：

  • 在依法设立的 产权交易场所 公开进行
  • 转让信息应当公开披露，披露期不少于 20个工作日
  • 产生两个以上受让方的，采取 公开竞价 方式
  • 转让价格不得低于经核准或者备案的评估结果

五、实务要点

1. ▲ 国企混改中的法律风险

▲ 混合所有制改革（混改）是当前国企改革的重点方向，但存在以下法律风险：

风险类型 具体表现 防范措施
定价风险 国有资产评估不实，转让价格偏低 严格履行评估程序，选择合格评估机构
程序风险 未经审批擅自转让国有股权 事先获得出资人机构批准，公开挂牌交易
控制权风险 混改后国有资本丧失控制力 合理设计股权结构和表决权安排
职工安置风险 混改引发职工权益纠纷 制定完善的职工安置方案
关联交易风险 混改过程中利益输送 关联方回避，独立评估

2. ▲ 国有股权转让的审批程序

▲ 国有股权转让涉及多层级审批：

企业内部决策 → 出资人机构批准 → 审计/评估 → 产权交易所挂牌 → 公开竞价/协议转让 → 工商变更登记

关键审批节点：

  • 出资人机构审批：转让方为中央企业的，由国务院国资委或财政部审批；转让方为地方国企的，由省级国资委审批。
  • 评估备案/核准：评估结果需经出资人机构核准或备案。
  • 进场交易：原则上应在产权交易所公开挂牌转让。

3. ▲ 国有资产流失的法律责任

▲ 国有资产流失是指国有出资人、国有企业及其工作人员违反法律、行政法规和有关规定，造成国有资产损失的行为。

主要责任形态：

  • 民事责任：赔偿国有资产损失
  • 行政责任：给予处分，包括降级、撤职、开除等
  • 刑事责任：构成犯罪的（如贪污罪、国有公司人员滥用职权罪），依法追究刑事责任

4. ▲ 国企合规管理要点

▲ 《公司法》第177条明确要求国家出资公司加强内部合规管理。2022年国务院国资委发布的《中央企业合规管理办法》进一步确立了国企合规管理的基本框架：

  • 合规管理体系建设：设立首席合规官，建立合规管理制度体系
  • 合规风险识别：定期开展合规风险排查和评估
  • 合规审查机制：重大决策事项须经合规审查
  • 合规举报机制：建立畅通的违规举报渠道
  • 合规考核：将合规管理纳入绩效考核体系

5. ▲ 国有资产评估与转让的实务要点

▲ 国有资产转让是实务中高频出现的合规事项，主要依据《企业国有资产法》及32号令等配套法规：

环节 实务要求 法律依据
评估 委托有资质的评估机构，结果报出资人机构核准或备案 《企业国有资产法》
披露 在产权交易所公开挂牌，披露期不少于20个工作日 32号令
竞价 产生两个以上受让方时，采取公开竞价方式 32号令
定价 转让价格不得低于评估结果 《企业国有资产法》

七、案例分析

案例：国有独资公司董事会越权处置重大资产

【案情】

城发建设集团有限公司是某市国资委出资设立的国有独资公司，主要承担城市基础设施建设与运营业务。2024年8月，城发公司董事会在未报请市国资委批准的情况下，以5:2的投票结果（共7名董事，2名投反对票），决定将公司名下一处核心商业地块以8000万元的价格出售给一家民营房地产公司。

投反对票的两名董事在表决时明确表示异议，并要求将异议意见记载于会议记录。资产出售完成后，市国资委审计发现该地块的市场评估价为1.05亿元，交易价格明显偏低，造成国有资产流失约2500万元。

【法律分析】

  1. 越权决议的效力：根据《公司法》第172条，国有独资公司的重大资产处置属于出资人职责机构决定或批准的事项，董事会无权自行决定。该决议因违反法律强制性规定而无效。

  2. 董事的赔偿责任：参与决议并投赞成票的5名董事，应当对因此给公司造成的2500万元损失承担赔偿责任。

  3. 异议董事免责：根据《公司法》第125条，投反对票并已记载于会议记录的2名董事，可以免除责任。

  4. 交易效力：资产购买方若为善意且已支付合理对价，需根据具体情况判断；若购买方与相关人员存在恶意串通，该交易可被撤销。如构成恶意串通损害国家利益，相关责任人还可能面临刑事责任。

  5. 行政与刑事责任：相关责任人员可能面临行政处分；造成国有资产流失数额巨大的，可能构成国有公司人员滥用职权罪。

【实务要点】

国有独资公司的重大资产处置必须报经出资人职责机构批准，董事会不得越权决定。越权决议无效，赞成票董事应对公司损失承担赔偿责任，投反对票并记载于会议记录的董事可以免责。

【实务启示】

▲ 国有独资公司治理中，董事会必须严格区分可自主决策事项和须报批事项。建议：

  1. 在公司章程中明确列举须报出资人机构批准的事项清单
  2. 建立重大事项合规审查前置程序
  3. 董事会秘书应确保异议意见完整记载于会议记录
  4. 董事应购买责任保险（D&O保险）以分散履职风险

案例：国有独资公司章程修改中的权限争议

【案情】

星耀科技集团有限公司是某省国资委出资设立的国有独资公司，主营新能源技术研发与产业化。2024年新《公司法》施行后，星耀公司启动章程修改工作。公司法律顾问团队提出以下修改方案：

  1. 将原章程中"修改章程须报省国资委批准"的条款删除，改为"授权董事会根据新《公司法》自行修改章程"；
  2. 在章程中增设审计委员会条款，同时删除原监事会相关章节；
  3. 章程中增设"股东会"专章，规定由省国资委行使股东会职权。

省国资委法规处在审查时对上述方案提出异议。

【法律分析】

  1. 方案一违法：根据《公司法》第172条，公司章程的制定和修改属于出资人机构须决定的8项事项（“7-1+2+担保”）之一，应当由履行出资人职责的机构决定，不得授权董事会自行决定。因此，删除报批条款并将修改权授予董事会的方案违反法律强制性规定，应予纠正。

  2. 方案二合法但非强制：根据《公司法》第176条，国有独资公司可以在董事会中设置审计委员会行使监事会职权，从而不设监事会。但设立审计委员会并非强制性要求，公司也可选择保留监事会或仅设一名监事。方案二本身合法，但应明确这是公司自治的选择，而非法律强制。

  3. 方案三错误：根据《公司法》第172条，国有独资公司不设股东会，由履行出资人职责的机构行使股东会职权。章程中不应设立"股东会"专章，而应明确由省国资委作为履行出资人职责的机构行使相关职权。

【最终处理】

省国资委要求星耀公司修改方案：（1）章程修改必须报省国资委审批，不得授权董事会；（2）审计委员会的设置属于公司自治范畴，由公司自行决定；（3）删除"股东会"专章，改为"履行出资人职责的机构"相关条款。

【实务要点】

国有独资公司章程修改的权限边界：修改章程本身属于出资人机构的法定职权，不可授权；但章程中具体治理结构的选择（如是否设审计委员会）属于公司自治范畴。两者的界限在于是否属于出资人机构须决定的8项事项（“7-1+2+担保”）。
