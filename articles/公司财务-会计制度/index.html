公司财务、会计制度

二、核心法条群

本章核心法条对应《公司法》第208条至第216条（第十章 公司财务、会计）。

三、核心制度详解

（一）财务审计

《公司法》第208条：

公司应当在每一会计年度终了时编制财务会计报告，并依法经会计师事务所审计。核心要求两点：

  1. 年审：公司应当在每一会计年度终了时编制财务会计报告
  2. 外审：财务会计报告应当依法经会计师事务所审计

▲ 实务提示：财务会计报告应当依照法律、行政法规和国务院财政部门的规定制作。上市公司的年度财务会计报告必须经具有证券业务资格的会计师事务所审计。

财务会计报告的组成（《会计法》第20条）：

组成 内容
会计报表 资产负债表、利润表、现金流量表、所有者权益变动表
会计报表附注 对报表项目的详细说明
财务情况说明书 生产经营、利润实现和分配、资金增减和周转等情况

▲ 实务重难点：财务会计报告应当在召开股东会年会的二十日前置备于本公司，供股东查阅（第209条）。

审计独立性保障（第215条）：

  • 公司聘用、解聘承办公司审计业务的会计师事务所，由股东会、董事会或者监事会决定（按章程规定）
  • 股东会、董事会或监事会就解聘会计师事务所进行表决时，应当允许会计师事务所陈述意见
  • 不得由经理等高级管理人员单独决定

（二）◆ 公司收益分配制度（★★★）

收益分配制度是公司法中最具实务重要性的制度之一。核心在于平衡股东的投资回报期望与公司资本维持原则。

1. 利润分配的前提条件

◆ 核心规则：股东分红必须以公司存在利润为前提；如无利润，不得进行分红，即"无盈不分"。

公司的利润形成路径：

营业收入 → 减去营业支出 → 营业利润 → 加上营业外收入、减去营业外支出 → 利润总额 → 扣除所得税费用 → 净利润（税后利润）

2. ◆ 公司收益分配顺序（核心重点）

除法律、行政法规另有规定外，利润按以下顺序分配：

graph LR
    A[净利润] --> B{有未弥补亏损?}
    B -->|有| C[弥补以前年度亏损]
    B -->|无| D[提取法定公积金 10%]
    C --> D
    D --> E{累计达注册资本50%?}
    E -->|是| F[可不再提取]
    E -->|否| G[必须继续提取]
    F --> H[提取任意公积金]
    G --> H
    H --> I[当年可分配利润]
    I --> J[向股东分配]

第一步：弥补以前年度亏损

  • 若公司存在未弥补亏损，应当先用当年净利润弥补亏损

第二步：提取法定公积金

  • ◆ 核心规则：公司分配当年净利润时，应当提取净利润的 10% 列入法定公积金
  • 若存在未弥补亏损，则提取额为弥补亏损后余额的 10%
  • 法定公积金累计额达到公司注册资本的 50% 以上，可以不再提取

第三步：提取任意公积金

  • 经股东会决议，还可以从税后利润中提取任意公积金
  • 任意公积金的提取比例由股东会决定，法律不作强制要求

第四步：向股东分配利润

  • 提取法定公积金、任意公积金后的余额，为当年可分配利润的上限
  • 公司持有的本公司股份不得分配利润

◆ 利润分配计算示例：

A有限公司2024年实现净利润500万元，上年度未弥补亏损为100万元。利润分配流程如下：

  1. 弥补亏损：500 − 100 = 400万元
  2. 提取法定公积金：400 × 10% = 40万元，余额为 400 − 40 = 360万元
  3. 提取任意公积金：经股东会决议，提取任意公积金60万元。余额为 360 − 60 = 300万元
  4. 向股东分配：股东会决议按照股东实缴出资比例分配，甲实缴出资比例10%，获得利润分配30万元

◆ 利润分配比例规则（第210条第四款）：

公司类型 默认规则 变更方式
有限责任公司 按股东实缴的出资比例分配 全体股东约定不按出资比例分配的除外
股份有限公司 按股东所持有的股份比例分配 公司章程另有规定的除外

注意区分：有限公司是"全体股东约定"（非章程规定、非股东会决议）；股份公司是"章程另有规定"。

3. ◆ 违法分配的后果

《公司法》第211条：

公司违反本法规定向股东分配利润的：

  1. 股东应当将违反规定分配的利润退还公司
  2. 给公司造成损失的，股东及负有责任的董事、监事、高级管理人员应当承担赔偿责任

违法分配的典型情形：

  • 未弥补亏损即分配利润
  • 未提取法定公积金即分配利润
  • 以公司资本金向股东分配（实为抽逃出资）
  • 股东会决议违反法律强制性规定

▲ 实务重难点：违法分配利润的，股东有义务退还已分配的利润。这一规定在实务中可能导致已获分红的股东面临退还风险，尤其在公司经营恶化、需要进行破产清算时。此外，负有责任的董监高亦需承担赔偿责任，注意此处是"股东退还 + 董监高赔偿"的双重责任。

4. 利润分配时间

《公司法》第212条：

股东会作出分配利润的决议的，董事会应当在股东会决议作出之日起 六个月内进行分配。

▲ 实务提示：这是新公司法新增的规定，明确了利润分配的时间约束。若董事会未在六个月内执行分配决议，股东可据此要求公司履行分配义务。

（三）◆ 公积金制度

公积金是指公司依法提列的、积累于公司内部，用于弥补未来公司亏损、扩大生产经营规模和转增资本的财产盈余。

1. 公积金的分类

（1）按提取依据分类：

类别 是否法律强制
法定公积金 基于公司法的强制规定而提取
任意公积金 由公司股东会决定是否提取（可提可不提）

（2）按来源分类：

公积金按来源不同，分为盈余公积金和资本公积金。盈余公积金源于公司税后利润（法定公积金和任意公积金均自税后利润中提取），资本公积金源于公司盈余之外的其他渠道。

类别 子类 来源
盈余公积金 法定公积金 ① 当年税后利润的 10%；② 累计额达到注册资本的 50% 以上的，可以不再提取
任意公积金 ① 提取法定公积金后，经股东会决议，还可以提取任意公积金；② 提取比例由股东会决定
资本公积金 ★ — ① 公司以超过股票票面金额的发行价格发行股份所得的溢价款（第213条）；② 发行无面额股所得股款未计入注册资本的金额；③ 国务院财政部门规定列入资本公积金的其他项目

2. 公积金的用途

（1）弥补公司亏损（第214条）：

弥补亏损的顺序：

  1. 先使用任意公积金和法定公积金弥补
  2. 仍不能弥补的，可以按照规定使用资本公积金弥补

注意：新公司法允许资本公积金弥补亏损，但必须在任意公积金和法定公积金用尽之后才能使用。

（2）扩大生产经营：无特殊规定，三类公积金均可使用。

（3）转增注册资本：

公积金类型 转增限制
法定公积金 所留存的法定公积金不得少于转增前公司注册资本的 25%
任意公积金 法律未明确规定具体的留存比例限制
资本公积金 法律未明确规定具体的留存比例限制

◆ 法定公积金转增资本计算示例：

A公司注册资本为100万元，法定公积金为50万元，经股东会决议以法定公积金转增注册资本。

限制：转增后法定公积金余额不得低于 100 × 25% = 25万元。 结论：最多将 50 − 25 = 25万元的法定公积金转为注册资本。

3. 公积金转增注册资本的路径

例：A公司注册资本10万元，共10万股，张某持有1万股，持股比例为10%。公司法定公积金20万元，现拟用10万元法定公积金转增为注册资本。

效果：

  • 注册资本变为 20万元，共 20万股
  • 张某持有股份变为 2万股，持股比例仍为 10%
  • 张某的权益无变化

要点：公积金转增注册资本，各股东按原持股比例增加股份，不改变股东之间的权益比例关系。

4. ◆ 对资本公积金的理解

资本公积金的实质：增资方为获得投资机会，就超出注册资本部分而履行的出资义务。

例：张三和李四创办A股份有限公司，各投入100万元，注册资本200万元，各持100万股，各占50%。王五拟向A公司增资：

方案1：出资200万元全部计入注册资本 → 注册资本400万元，王五占50%。原股东不能接受。

方案2：出资2000万元，其中200万元计入注册资本，1800万元计入资本公积金 → 注册资本400万元，新老股东各占50%。

分析：王五出资2000万元获得50%股权，而原股东各出资100万元即获得25%股权，差额1800万元即为王五为获得投资机会而支付的溢价，计入资本公积金。

四、▲ 实务重点与典型案例

（一）资本公积金实务——"某爽"逃税案

某爽拍摄电影，与制片方确定片酬为16000万元（1.6亿元）。为规避明星限薪令（演员片酬不得超过5000万元）及避税，与制片方作如下安排：

  1. 演出报酬确定为4800万元（属于劳务收入，须缴纳个人所得税）
  2. 余下11200万元由制片方向某爽母亲实际控制的上海晶焰沙科技有限公司增资，其中 888.88万元 计入注册资本（占增资后10%），其余 10311.12万元 计入资本公积金

效果：由于增资部分无须缴纳企业所得税或个人所得税，从而达到了逃税目的。

▲ 实务启示：资本公积金在实务中可能被用于规避税收、转移利润等不当目的。理解资本公积金的本质（超出注册资本的出资溢价），有助于识别此类安排中的法律风险。

（二）◆ 利润分配合规计算实务

【案情】

紫霞股份有限公司是一家从事游戏开发的非上市公司，注册资本5000万元，已发行股份1000万股。公司成立后经营状况一直不佳，至2015年底公司账面亏损3000万元。2016年初，公司开发出一款爆款游戏，年底即扭亏为盈，税后利润达7000万元。此时公司法定公积金余额仅为5万元。公司拟于2016年底进行利润分配，董事会委托你作为法律顾问审查分配方案的合规性。

【合规审查要点】

1. 弥补亏损

公司存在未弥补亏损3000万元，应当先以当年税后利润弥补：

7000 − 3000 = 4000万元（弥补亏损后的可分配基数）

2. 提取法定公积金

法定公积金的提取基数为弥补亏损后的余额，而非当年税后利润总额：

4000 × 10% = 400万元

▲ 实务易错点：法定公积金的提取基数是"弥补亏损后的余额"（4000万元），而非"当年税后利润"（7000万元）。若错误按7000万元计算，会得出700万元的错误结论。

法定公积金累计余额：5 + 400 = 405万元，远未达到注册资本的50%（2500万元），故必须提取，不能以"已达50%"为由免除。

3. 提取任意公积金

提取法定公积金后余额为：4000 − 400 = 3600万元。

任意公积金的提取须经股东会决议，提取范围为0~3600万元。例如股东会决议提取1000万元任意公积金，则：

可分配利润 = 3600 − 1000 = 2600万元

4. 向股东分配

向股东分配利润的上限为弥补亏损、提取公积金后的余额。须注意：

  • 分配比例：按股东持股比例（股份公司，章程另有规定除外）
  • 分配时限：股东会决议作出之日起6个月内（第212条）
  • 公司持有的本公司股份不得分配利润

【合规结论】

审查事项 合规要求 本案例情况
弥补亏损 必须先弥补 已弥补3000万元，基数为4000万元
法定公积金 基数的10%，累计未达注册资本50%必须提取 应提取400万元
任意公积金 股东会决议，金额在0~3600万元之间 由股东会决定
可分配上限 弥补亏损和提取公积金后的余额 最高3600万元（不提任意公积金时）
分配时限 决议作出之日起6个月内 须在2017年6月底前完成

▲ 实务启示：律师审查利润分配方案时，应逐项核对"弥补亏损→法定公积金→任意公积金→可分配利润"四个环节，重点关注法定公积金的提取基数（弥补亏损后而非当年利润总额）和累计是否已达注册资本50%的门槛。常见的违规情形包括：以当年利润总额为基数计算法定公积金（多提）、未弥补亏损即分配（违法分配）、未在6个月内执行分配决议（程序违规）。

（三）◆ 股东分红权的实现

1. 分红权之诉的请求权基础

股东分红权的实现需要满足两个条件：

  • 实体条件：公司有可供分配的利润（已弥补亏损、已提取公积金）
  • 程序条件：股东会作出利润分配决议

司法实践中的处理规则：

  • 未作出利润分配决议的，股东一般不得直接起诉请求分配利润
  • 例外情形：大股东滥用股东权利，导致公司不分配利润，给其他股东造成损失的，法院可以例外支持分红请求（《公司法司法解释四》第15条但书）

2. 公司长期不分红的递进救济

graph TD
    A[公司长期不分红] --> B{公司是否有可分配利润?}
    B -->|无| C[经营问题，需另寻救济]
    B -->|有| D{是否作出分配决议?}
    D -->|否| E[行使知情权查阅财务报告]
    E --> F[提起分红权之诉]
    F -->|大股东滥用权利| G[法院判决分配]
    F -->|无滥用证据| H[驳回诉讼请求]
    D -->|是但未执行| I[请求公司执行决议 6个月内]
    A -->|严重经营管理困难| J[提起公司解散之诉]

递进式维权路径：

  1. 知情权之诉（第57条）：股东有权查阅、复制财务会计报告，查阅会计账簿和会计凭证；可委托会计师事务所协助
  2. 分红权之诉（第210条）：在公司有利润且大股东滥用权利的情况下，请求法院判决分配
  3. 异议股东回购请求权（第89条）：公司连续五年不向股东分配利润，而公司该五年连续盈利且符合法定分配利润条件的，异议股东可请求公司以合理价格收购其股权
  4. 解散之诉（第231条）：公司经营管理发生严重困难，继续存续会使股东利益受到重大损失

五、实务案例

案例：大股东利用不分红排挤小股东

【案情】

鸿达建材贸易有限责任公司有甲、乙、丙三名股东，持股比例分别为60%、25%、15%，公司主营瓷砖和卫浴产品的批发零售业务。自2019年至2023年，鸿达公司连续五年盈利，年均税后利润超过500万元，已弥补全部历史亏损，法定公积金累计已达注册资本的55%。

甲作为控股股东兼执行董事，连续五年以"公司计划开设新门店、需要积累发展资金"为由，操纵股东会否决乙和丙提出的利润分配议案。乙和丙多次要求查阅公司财务报告，均被甲以各种理由推脱拒绝。

2024年初，乙和丙注意到甲通过鸿达公司向其个人控制的另一家装修公司低价供货，怀疑甲存在关联交易输送利益的行为，遂决定通过法律途径维权。

【法律分析】

1. 知情权救济

  • 乙、丙有权依据《公司法》第57条要求查阅公司财务会计报告、会计账簿和会计凭证
  • 公司拒绝的，股东可提起知情权之诉
  • 乙、丙还可以委托会计师事务所协助查阅

2. 分红权救济

  • 鸿达公司连续五年盈利，且符合利润分配条件（已弥补亏损、已提取法定公积金且累计已超过注册资本50%）
  • 甲作为控股股东，利用表决权优势连续否决分配议案，构成"滥用股东权利"
  • 乙、丙可依据《公司法》第210条和《公司法司法解释四》第15条但书，提起分红权之诉
  • 法院可以在审查公司财务状况的基础上，径行判决公司向股东分配利润

3. 解散公司之诉

  • 如甲的行为已导致公司经营管理发生严重困难，乙、丙可依据《公司法》第231条提起公司解散之诉
  • 但解散之诉的门槛较高，需证明"继续存续会使股东利益受到重大损失"

4. 退出路径

  • 乙、丙可依据《公司法》第89条请求公司以合理价格收购其股权（异议股东回购请求权）
  • 条件：公司连续五年不向股东分配利润，而公司该五年连续盈利，并且符合法定分配利润条件

【实务启示】

▲ 中小股东遭遇长期不分红时，建议采取"知情权 → 分红权 → 回购权 → 解散之诉"的递进式维权策略。实务中，知情权之诉往往是最有效的第一步——通过查阅财务资料，获取大股东侵害公司利益的证据，为后续分红权之诉和关联交易诉讼奠定证据基础。

七、实务要点

  1. 利润分配的合规审查：公司在进行利润分配前，应当严格按照"弥补亏损 → 提取法定公积金 → 提取任意公积金 → 分配利润"的法定程序进行，违反程序的分配可能被认定为违法分配，股东需退还已分配利润
  2. 法定公积金的"双10%/50%"规则：提取比例为税后利润的10%，累计达注册资本50%可不再提取——这是常考的数字陷阱
  3. 有限公司分红的"全体股东约定"：有限公司不按实缴出资比例分红，须经全体股东一致同意（非章程规定或股东会多数决），这一要件远高于股份公司
  4. 公积金弥补亏损的顺序：任意公积金 + 法定公积金 → 资本公积金（依次使用，不可跳过）
  5. 法定公积金转增资本的25%限制：转增后法定公积金余额不得低于转增前注册资本的25%
  6. 利润分配的6个月时限：新公司法明确董事会应在股东会决议作出之日起6个月内进行分配，超期股东可主张权利
  7. 分红权之诉的举证要点：原告股东需要证明公司存在可供分配的利润、大股东存在滥用权利的行为；知情权之诉往往是第一步
  8. 审计报告的保存：公司应当妥善保存财务会计报告和审计报告，以备股东查阅和监管机构检查
